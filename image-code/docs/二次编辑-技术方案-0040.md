## 1. 入口契约（Q1 / E-④ 定案：source_image_key 单一不透明 handle）

请求只携带 `source_image_key`（= `listing_image.image_key`，`<sha16>.png`）。服务端由 key 反解全部上下文：行 → join 源 job（即 parent_job_id，客户端不传）→ owner → 沿链取根。

三案权衡：

| 案 | 判定 |
|---|---|
| 1 parent_job_id+image_index | **否**。PRD 红线"客户端不拼组合键"直接排除；且 `images` relationship 无 order_by，index 非稳定身份 |
| 2 暴露 listing_image.id（int 自增） | 可用但次优：全局自增可枚举（虽有 ownership-404 兜底）；与已签 source_image_key 列之间多一次 id→key 翻译 |
| 3 image_key 直接作 handle | **✅** sha 文件名构造性防枚举；与已签列零翻译（请求 shape 即列 shape）；服务端可由 key 反解 parent 链，客户端连 parent_job_id 都不知道 |

**内容寻址注记**（设计如实）：`image_key = sha256(bytes)[:16]+suffix`，同字节图同 key——理论上 key 可对应多行。反解查询收敛为：
`WHERE image_key=? AND job.user_id=:user AND image.status='成功' ORDER BY image.created_at DESC LIMIT 1`
——一条谓词同时完成 owner 过滤（D1 第一核）、失败张排除（Q-δ）、多行收敛（取本人最新）。无行 → 404，文案同 anti-enum 口径（不区分不存在/他人/失败）。

**handle 下发面**：`ListingImageOut` 增 `image_key` 字段（读侧 `ListingJobImageView` 已有，纯 Out 层补暴露）。SSE 契约冻结（#638/#639）；frontend 两处入口（历史详情 + 结果区完成后补拉）同一读模型取 handle（#640 口径：补拉是前端为入口新加的一步）。

## 2. 端点（Q-α 定案：瘦路由 POST /listing/edit）

沿 /clone (b) 先例：listing router 内新增独立瘦端点，不污染 generate 的 plan/n 语义。

```python
class EditRequest(BaseModel):
    model_config = ConfigDict(extra="forbid")   # E-⑥：未知字段(含 overlay_texts/n/plan)→422
    source_image_key: str
    edit_mode: str = "delta"        # delta|full；registry fail-fast→400（沿 clone_mode 先例，单一事实源在卡）
    # E-⑤ 必填。QA #652 收敛单值 422：StringConstraints(strip_whitespace=True, min_length=1)
    # 先 strip 再验长 → ""/"  " 都 422，与 extra=forbid 同层同码、单层实现（无 400/422 分裂）
    prompt: Annotated[str, StringConstraints(strip_whitespace=True, min_length=1)]
    modifiers: dict[str, str] = {}  # 叠新，见 §4
    ratio: str | None = None        # delta：必须缺省，显式提供→400（继承即契约，矛盾输入不静默忽略）
                                    # full：None=继承父，显式=覆盖（过 ratio_to_size 校验）
```

**不收 category**（R2，请 PM 确认 PRD 字面）：编辑组装不含品类保真块（#645 卡自含保真），listing_job 亦无 category 列——category 在编辑流没有任何消费点，收了就是死参数，fail-fast 哲学不收。PRD A.2/A.3 的"category 继承/可改"建议改写为"不适用：编辑组装不含品类块"。

## 3. 校验矩阵（0024 口径，顺序即代码序；频控后置不破探针契约）

状态码分层（QA #652 收敛）：**shape 约束全 422**（extra=forbid 未知字段、prompt 空/空白 经 strip_whitespace+min_length 单层实现）；**域值校验全 400**（edit_mode/ratio 走 registry/ratio_to_size——单一事实源在卡与映射表，与全项目图型/clone_mode/平台枚举同构）。

| # | 校验 | 失败响应 |

| 1 | body 形状 / extra=forbid / prompt 非空白 / 类型 | 422（QA 空 body 探针走此层，碰不到频控） |
| 2 | edit_mode 经 EditModeRegistry | 400（未知档位） |
| 4 | ratio 规则：delta+显式 ratio→400；full+显式 ratio→ratio_to_size | 400 |

| 6 | 沿 parent_job_id 走到链根；**顺路核每跳 user_id**（D1 第二核，防御性零额外成本）；环不可能（parent 服务端生成、只能指向既存 job=DAG 拓扑序）；深度无上限（PM A.7），O(深度) 单行查询 | 404 |

## 4. 喂图与组装

- **喂序**（#635 包络 + #645 卡角色措辞对齐）：`[源图(基底)] + [链根锚 1..3]` = 总 2..4 张 → provider `/images/edits` image[]。
