# Wan 2.7 Image Pro 能力与选择器设计

## 目标

以阿里云百炼官方契约为事实源，修正 `wan2.7-image-pro` 在图片模型目录中的分辨率档位与比例，并用四个极端比例的真实文生图调用做冒烟验证。

## 官方能力口径

- 无参考图、非组图的文生图支持 1K、2K、4K。
- 有参考图、图片编辑和组图生成最高支持 2K。
- 自定义输出尺寸的宽高比范围为 1:8 到 8:1。
- 文生图自定义尺寸总像素范围为 768×768 到 4096×4096；其他场景最高为 2048×2048。
- 输出尺寸可能被上游微调，因此验证以请求成功、结果为有效图片且实际比例接近目标为准。

## 选择器能力

万相在平台现有比例词汇内开放以下 16 个离散选项：

`1:1`、`1:4`、`1:8`、`2:3`、`3:2`、`3:4`、`4:3`、`4:1`、`4:5`、`5:4`、`8:1`、`9:16`、`16:9`、`1:2`、`2:1`、`21:9`。

这些比例均位于官方连续区间 1:8 到 8:1 内。后端模型目录为万相返回 1K、2K、4K 三档及各档比例；前端继续从目录契约渲染，不单独硬编码万相选项。

4K 是场景相关能力：纯文生图可选；存在上传参考图或编辑底图时不可选。前端据当前输入上下文隐藏 4K，后端在任务提交前再次校验，避免把无效请求发给上游。

## 尺寸映射

为每个档位和比例维护明确的输出尺寸映射。映射遵循目标总像素、目标宽高比和上游尺寸约束，不复用 GPT Image 或 Nano Banana 的模型契约。万相 Provider 直接使用该映射生成 `宽*高` 请求参数。

旧的 `_WAN_TIER_RATIO_SIZES = {standard: GPT_IMAGE_2_STANDARD_RATIO_SIZES}` 被完整替换，不保留兼容分支。

## 真实冒烟验证

使用 `wan2.7-image-pro`、无参考图、非组图、1K、单张输出，分别调用：

- `1:4`
- `4:1`
- `1:8`
- `8:1`

每次记录目标比例、请求尺寸、任务 ID、最终状态和实际图片尺寸。通过条件：上游任务成功、下载内容是有效图片、实际宽高比相对目标误差不超过 3%。任一调用失败时立即保留证据并暂停能力发布，先报告官方契约与实测不一致，不做重试、静默替代或只排除失败比例。

四次调用可能产生约 2 元费用，具体以阿里云账单和免费额度为准。

## 测试与验收

- 后端单元测试覆盖万相三档能力、16 个比例、4K 场景限制和尺寸映射。
- Provider 测试覆盖发送给上游的 `size`。
- 模型目录 API 测试覆盖万相返回的档位与比例。
- 前端测试覆盖选择万相后的档位、比例，以及参考图场景隐藏 4K。
- 运行后端相关测试、前端相关测试与前端生产构建。
- 四次真实调用生成的图片和结果索引保存到 `image-code/exports/wan-capability-smoke/`，该运行产物不提交 Git；提交脱敏后的验证摘要。

## 非目标

- 不增加连续比例自由输入。
- 不测试全部 48 个“档位 × 比例”组合。
- 不修改万相价格、密钥、默认模型或启停状态。
- 不改变 GPT Image 2 与 Nano Banana 2 的能力契约。
