## 0. 一分钟全景

- **是什么**：设计师 AI 副驾驶中台。核心引擎 = 产品图 → 高质量电商图（图生图）。
- **架构**：六边形（Ports & Adapters），依赖一律指向内 `domain ← ports ← application ← infrastructure ← interface`。绝对导入。
- **技术栈**：Python 3.12 · uv · FastAPI · SQLAlchemy 2.0 async · Alembic · arq · Redis · MySQL(本地, PRD 原定 PG) · httpx。
- **质量门禁**：`uv run ruff check src` + `uv run mypy`(strict) 必须全绿。
- **铁律**：SOLID 强制；Dev 角色**不写测试**(测试归 image-qa)；**涉及 DB 先问用户**；密钥只走 `.env`(gitignored) 不入库；完成一单元即 commit。
- **进度概数**：出图引擎后端 ≈ 完成；中台业务后端 ≈ 5-6 成(WP-A/B/C/E/F/H 已交付)；前端 = 0%。整体剩余 ≈ 30 人天(砍 M4 后 ≈21；不含前端 ≈12)。

## 3. 后端接口清单

### 3.1 已实现（4 个，已接真实 gpt-image）

> 公共请求头：`X-User-Id: <设计师标识>`（默认 `designer-anon`）。
> 同步应用 `design_hub.interface.api.app:app`（全 Mock）；生产应用 `design_hub.interface.api.asgi:app`（真实 MySQL+Redis+gpt-image）。**生产 asgi 全端点需 `Authorization: Bearer <JWT>`（WP-G）；仅 `/auth/*` 公开。**

**`POST /generate`** — 同步出图
```jsonc
// Request (GenerateRequest)
{
  "customer": "客户A",
  "subscene": "S1",            // S1换背景 | S3场景图 | S4多角度
  "family": "family_4",        // family_3/4/5/7 (V1)
  "tier": "standard",          // draft | standard | refine
  "style": "高端轻奢",          // 国潮中式|极简北欧|高端轻奢|科技未来|清新自然|运动机能
  "category": "3C数码",         // 3C数码|服饰配件|美妆护肤|食品 (V1有画像)
  "width": 1024, "height": 1536,
  "n": 6,                      // 1..12
  "copy_text": "焕新水光",       // 可选
  "taboo": null, "product_desc": null, "brand_name": null
}
// Response (GenerateResponse)
{
  "used_model": "gpt-image-2",
  "total_cost": "1.20",
  "positive_prompt": "…", "negative_prompt": "…",
  "images": [{"url": "...", "seed": 100, "latency_ms": 80000, "cost": "0.10"}]
}
```
> 备注：扁平 `/generate` 的 HTTP schema 仍无图片上传字段；**图生图经 HTTP 走通已由 WP-B 提供**——`POST /projects/{id}/assets` 上传素材 + `POST /projects/{id}/generate` 传 `asset_ids[]`，pipeline 自动切 EDIT 模式。

**`POST /generate/cost-preview`** — 出图前成本预估（只读不预扣）。请求同上，返回 `{tier, candidate_count, model, estimated_cost, month_used, month_budget}`。

**`POST /generate/async`** — 入队，返回 `{"job_id": "<hex>"}`。请求同 `/generate`。

**`GET /generate/{job_id}/events`** — SSE 进度流。事件：`task_started / model_called / image_generated / task_completed / task_failed`，`data` 为 JSON。

**边界错误映射**：`AuthenticationError→401` / `PermissionDenied→403` / `NotFoundError→404` / `BudgetExceeded→409` / `DomainError→409` / `ValueError→400` / `KeyError(未实现族/品类)→400` / `ProviderError→502`。
