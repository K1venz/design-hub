# 顶部导航与 Footer 备案底栏设计

## 目标

将现有左侧导航重构为居中的顶部浮动导航，并把公共 Footer 的备案信息整理为正式横向底栏。整体延续现有玻璃拟态和紫色品牌色，不改变业务路由及页面内容。

## 顶部导航

- 删除桌面端左侧导航，页面恢复为完整宽度的纵向布局。
- 顶部导航为居中的短浮动胶囊，桌面端最大宽度 `840px`，左右随视口留白。
- 使用三列网格：左侧品牌 Logo、中间主功能、右侧个人中心，保证主功能图标组相对视口严格居中。
- 品牌区只显示透明背景 Logo，显示尺寸为 `26 × 30px`，不显示“实朴”文字。
- 点击 Logo 跳转 `https://image.sepaitech.com/`。
- 主功能依次为：首页、帮我设计、商品套图、爆款复刻、历史。
- 桌面端默认仅显示图标；悬停或键盘聚焦后在 `200ms` 左右展开中文名称。
- 当前路由使用紫色实底突出，仍可在悬停或聚焦时展开名称。
- 移除“内测”和“内测免费”字样。
- 右侧头像改为 Profile 图标，与主功能图标保持同一套交互；展开文字为“个人中心”。
- 已登录用户点击 Profile 后显示用户信息和退出登录；管理者额外显示模型配置、用户管理。
- 未登录用户点击 Profile 后显示登录、注册入口。
- 移动端不依赖悬停，顶部显示 Logo、菜单按钮和 Profile；菜单内直接展示五个中文功能名称。
- 工作台“新建任务”按钮移动到导航下方的页面操作区，不挤占顶部导航的严格居中结构。

- ICP 备案号继续链接 `https://beian.miit.gov.cn`，新窗口打开。

## 视觉方案

- 保持现有浅色 Footer，不引入与页面割裂的深色区域。
- 在主导航和法务链接区域下方增加独立备案底栏。
- 底栏顶部使用一条低对比度细分隔线。
- 桌面端文案单行居中，使用弱化灰色小字号。
- 移动端允许自然换行，并保持内容居中、间距清晰。
- 不展示公安徽章；该徽章仅应与真实的公安联网备案号共同使用。

## 改动范围

- 重构 `AppShell`、`AppTopBar` 和 `WorkbenchLayout`，删除不再使用的 `SideNav`。
- 新增专用导航数据模块，作为桌面和移动导航的单一事实源。
- 新增透明品牌 Logo 资源。
- 修改 `SiteFooter` 的备案区域，不改变品牌、联系方式、主导航和法务链接。
- 所有使用 `SiteFooter` 的页面自动获得相同备案底栏。

## 验收

1. 桌面端不再显示左侧导航，顶部主功能组相对视口居中。
2. Logo 尺寸协调、背景透明，点击指向 `https://image.sepaitech.com/`。
3. 五个功能图标可访问，悬停和键盘聚焦均能展开中文名称。
4. Profile 菜单按登录状态和角色展示正确入口。
5. 移动端菜单可打开、关闭并直接读取中文功能名称。
6. 首页、协议页和隐私页显示相同的备案底栏。
7. ICP 备案号文字和链接准确，公司主体显示为“浙江实朴数据科技有限公司”。
8. 桌面端备案信息单行居中；窄屏下不溢出、不遮挡。
9. 前端 lint、typecheck、test 和 build 通过。
