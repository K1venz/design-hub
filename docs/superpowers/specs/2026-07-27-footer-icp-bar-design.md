# Footer ICP 备案底栏设计

## 目标

将全站公共 Footer 的备案信息整理为参考图所示的正式横向底栏，同时只展示已有真实信息，不添加公安联网备案徽章或虚构备案号。

## 最终内容

- ICP 备案号：`浙ICP备2026024031号-1`
- 版权主体：`浙江实朴数据科技有限公司`
- 完整文案：`浙ICP备2026024031号-1 · Copyright © 2026 浙江实朴数据科技有限公司`
- ICP 备案号继续链接 `https://beian.miit.gov.cn`，新窗口打开。

## 视觉方案

- 保持现有浅色 Footer，不引入与页面割裂的深色区域。
- 在主导航和法务链接区域下方增加独立备案底栏。
- 底栏顶部使用一条低对比度细分隔线。
- 桌面端文案单行居中，使用弱化灰色小字号。
- 移动端允许自然换行，并保持内容居中、间距清晰。
- 不展示公安徽章；该徽章仅应与真实的公安联网备案号共同使用。

## 改动范围

- 仅修改 `image-web/src/components/layout/SiteFooter.tsx`。
- 不改变 Footer 的品牌、联系方式、主导航和法务链接。
- 所有使用 `SiteFooter` 的页面自动获得相同备案底栏。

## 验收

1. 首页、协议页和隐私页显示相同的备案底栏。
2. ICP 备案号文字和链接准确。
3. 公司主体显示为“浙江实朴数据科技有限公司”。
4. 桌面端单行居中；窄屏下不溢出、不遮挡。
5. 前端 lint、typecheck、test 和 build 通过。
