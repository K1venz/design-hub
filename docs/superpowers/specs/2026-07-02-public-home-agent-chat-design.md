4. **新首页=公开落地页**：不登录可看（浏览 Hero/工具卡/成果区）；**点快捷卡/发送/进工具时才要求登录** → 顺手补 toC gate 7.G「对外落地页」。

## 三、页面结构（新公开首页 `/`）

- **左侧竖形导航**（决策 2 清单；未登录可见但点击受保护项→登录；管理仅 manager 可见）。
- **右上**：「内测免费」徽标（决策 3）+ 未登录「登录/注册」按钮 / 已登录头像。
- **① Hero**：大标题「和我聊聊，你想要什么设计？」+ 超大输入框（左下：＋添加图片；右下：发送）+ **6 张快捷卡=实朴真实创作预设**：白底主图 / 场景图 / 卖点图 / 整套套图 / 爆款复刻 / 二次编辑（点卡=预填对话意图，未登录先登录）。
  - 美图的「素材库/样机/灵感」圆钮与「AI 团队」开关**不做**（无对应能力，拒假门）。
- **② 工具区**：两张大 banner 卡=**商品套图** + **爆款图复刻**（直达现有工作台）；宫格=真工具（单图出图 / 二次编辑 / 历史）+ 至多 2 张**明确标「即将上线」**的预告卡（AI 消除 / 智能扩图，取自美图迁移调研第一波）。
- **④ 成果展示区**：横向滚动案例卡（before→after 出图对比的设计位），**首发用占位内容 + 懒加载**（进入视口才加载、skeleton 骨架）；后续填真实案例。
- **⑤ Footer**：产品导航 / 《用户协议》《隐私政策》真页面（注册页勾选链接从 `#` 接到这里）/ ICP 备案号占位（等备案下来填真）。
- 现有登录后工作台路由不变；登录后 `/` 也是这个首页（首页即门面+入口枢纽）。

## 四、「帮我设计」真 Agent（方案 C，零框架 tool-use 循环）

**后端（image-code，六边形内嵌、零新框架依赖）**：
- `TextLLMPort`（端口）+ 中转站适配器：首选 **DeepSeek**（≈¥0.05/会话）；apinebula 可中转 Claude 文本模型作质量对照——**具体可用模型/密钥 dev 先探明**（若需新开 key/供应商=报用户）。
- `ChatOrchestrator`（application 层）：多轮对话澄清（品类/图型/张数/比例/文案）→ 选工具 → 组装参数调**现有** `POST /listing/generate|clone|edit`（**不绕过卡体系、不造新出图链路**）→ 把 job SSE 转发给会话流。
- 新 `POST /chat`（或 `/chat/events` SSE）：登录必须（CurrentUserDep）；**复用**成本守卫/频控/owner 隔离（进程内自动继承）；出图确认前**必须回显预计费用**（¥/张 × N）由用户在对话里确认——防"聊着聊着被扣钱"。
- fail-fast：LLM 不可用→明确报错不装死；业务 4xx 不重试。
- **DeerFlow 借鉴的是"形式"**：流式 token、步骤/计划可见（「已理解需求→正在出图 3/5」）、工具调用透明；**不引 LangGraph/litellm**。
- ⚠️ 若 orchestrator 需要新表（会话历史持久化）：**MVP 用内存会话（单进程内）+ 不落库**，避免动 DB 签字；会话持久化二期另议。

**前端（image-web）**：
- `/chat` 会话页：流式气泡 + Agent 步骤条（DeerFlow 式）+ 出图结果卡内嵌（复用 ResultGallery 槽位思路/SSE 模式）+ 费用确认交互；Style 4。
- Hero 输入框提交 → 未登录先登录 → 带着首句进 `/chat`。

**放量边界**：「帮我设计」挂**内测标**、仅登录用户可用；对公众全量前，内容安全（PRD §7.B）是硬前置（本期不做、入档提醒）。

## 五、范围外（YAGNI/防假门）

模板区、AI 团队多专家编排、会员/支付入口、素材库/样机/灵感钮、视频/海报等未有能力的快捷卡、会话历史落库（二期）。

## 六、验收要点

① 未登录可浏览首页全部版块；点快捷卡/发送/工具→登录墙→回跳继续。② 对话能走通至少三条真路径：「给我的花生出一套 5 张」→套图 job 真出图回显进度与结果；「照这张爆款出一张」（带图）→clone；「把这张改成暖色调」→edit。③ 出图前对话内费用确认，计费与工作台口径一致。④ 成果区懒加载（skeleton→占位卡），不阻塞首屏。⑤ Footer 协议页真实可读，注册页勾选链接指向它。⑥ 现有工作台/历史/管理全链零回归。⑦「即将上线」卡不可点且标注清晰。
