# 爆款复刻「完全复刻」改版 — 设计稿

- 日期：2026-06-15
- 状态：用户已拍板（档结构 + 完全复刻"三贴一隔" + overlay_texts 选填 verbatim + 文案来源 A 方案）
- 背景：项目交付美工实际使用后，用户反馈现有复刻效果不理想。

## 一、背景与问题

现有复刻两档：`参考风格`(松) / `高度复刻`(紧)。当前「高度复刻」两个不足：
1. 图片风格贴得不够彻底；
2. 参考图文字被**整体排除**（成品无大标题字）→ 缺爆款那种"带大字标题/卖点角标"的版式感。

用户要：图片风格**完全复制** + 输出要有爆款的**文字样式**，但**不抄竞品文案**、也**不让模型自编文案**（避免重蹈 0038 糊字/乱编）。

## 二、决策（用户拍板）

1. **文案来源 = A**：用户显式提供 `overlay_texts`，模型按参考图的字体/排版**样式**把用户的字 **verbatim** 渲染上去。
2. **档结构**：`参考风格`(不变) + `高度复刻` → 逻辑整个改造为「**完全复刻**」（界面标签 + `clone_mode` 值同步改名为"完全复刻"）。
3. **overlay_texts 选填**：填则按参考样式上字；不填则纯风格、不上字。

## 三、「完全复刻」行为定义（三贴一隔 + 保真）

- ✅ **图片风格完全复制**：构图 / 场景 / 光影 / 配色 / 版式 / 背景，最大程度贴参考图（比现状更彻底）。
- ✅ **文字样式复刻**：字体 / 字号 / 字重 / 位置 / 颜色 / banner·角标 等**排版样式**照参考图。
- ✅ **文案内容来自用户**：输出文字 = 用户 `overlay_texts`，**verbatim 原样**；不填则不上字。
- ❌ **参考图文案一律不抄**：竞品大字（如"颗粒饱满 香脆可口"）**零泄漏**。
- 🔒 **产品保真不变**：产品 / 包装 / 品牌字 严格保真（复刻一贯命门，不动）。

## 四、改动落点（owner 三档清单）

- **dev**（image-code）：
  - `POST /listing/clone` 加 `overlay_texts`（选填，复用套图卖点图那套 verbatim 上字块/常量，勿造新机制）。
  - 物化块同步 + 卡↔code 逐字核对 pytest 闸扩。
  - `clone_mode` registry/枚举值 `高度复刻` → `完全复刻`（中文 key 值变更）。**⚠️ 若涉及 listing_job 存量行/迁移，dev 先评估上报——动 DB 要用户签字（铁律）**；prod 复刻历史已基本清空，预计 cosmetic 无需迁移，dev 确认。
- **prompt**（image-prompt）：复刻模式卡「完全复刻」块**重写**——风格全贴层 + 文字样式贴层 + 文案走 overlay verbatim + **显式禁抄参考图文案**。这是本次提示词主战场。
- **frontend-b**（image-web）：复刻 UI 加 `overlay_texts` 文案输入（复用卖点图输入组件）+ 档标签"高度复刻"→"完全复刻"。
- **QA**：视觉核 + 用 `admin@design-hub.cn` 账号跑 **2 个完全复刻测试**验收（凭据走临时文件传，不入群聊）。

## 五、提示词难点（prompt 重点攻）

让图像模型同时做到："**复刻参考图的文字呈现样式**（字体/字号/排版/色/banner），但渲染的内容是**用户 overlay_texts 的文字**、**绝不复制参考图的文字内容**"。措辞要同时锁住三件事：贴样式 + 换成用户内容 + 禁抄原文——避免模型把参考图原文也搬上来，或在无 overlay 时自编文案。

## 六、验收标准（admin 账号 2 测试）

① 图片风格贴参考图（构图/光影/版式）；② 文字按参考样式、内容=用户 overlay（或不填则无字）；③ 竞品文案零泄漏；④ 产品保真无走样；⑤ 无糊字乱码。
测试账号 `admin@design-hub.cn`（凭据临时文件传 QA）；测试 footprint 处置（admin 自有账号）由 QA/ops 按真实用户保障纪律定。

## 七、不做（YAGNI）

- `参考风格` 档不动（本次仅改「完全复刻」）。
- 不引入"模型自动生成文案"（C 方案排除，0038 风险）。
- 不动产品保真逻辑（命门，沿用现有复刻保真块）。

## 八、落地编排
