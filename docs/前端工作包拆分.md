# 前端工作包拆分（FE-1~7 并行协调卡）

> 用途：**多 agent 并行施工前端业务页的交接看板**。FE-0 骨架已就绪，新窗口零上下文照此领卡。
> 基座：`image-web/`（FE-0 完成）。契约源：`docs/项目状态与接口清单.md` §3 + `image-web/src/api/schema.d.ts`。
> 写边界：只写 `image-web/`；需后端改动 → `image-issues` 开条目（owner=开发）。
> 最近更新：2026-06-02。

---

## 0. FE-0 已提供（所有 FE-x 复用，勿重造）

| 能力 | 落点 | 说明 |
|---|---|---|
| 类型化契约客户端 | `src/api/client.ts` + `schema.d.ts` | `openapi-fetch`，Bearer 自动注入、401 清会话跳登录。**直接 `api.GET/POST(...)`**。 |
| 契约再生 | `npm run gen:api`（读 `openapi.json`） | 后端契约变更后重新生成类型，勿手改 `schema.d.ts`。 |
| 鉴权会话 | `src/stores/auth-store.ts` | Zustand persist；`useCurrentUser()` 取当前用户；`ROLE_DESIGNER/ROLE_MANAGER`。 |
| 路由守卫 | `ProtectedRoute` / `RoleRoute` | 登录闸门 + /me 引导；管理者页用 `<RoleRoute allow={[ROLE_MANAGER]}>` 包裹。 |
| 应用骨架 | `AppLayout` + `nav.ts` | 按角色导航；**新页在 `nav.ts` 登记一行 + `App.tsx` 加一条 Route 即接入**。 |
| 错误/加载 | `errors.ts`(归一后端错误体) · `FullPageLoader` · `sonner`(toast) | 统一 `errorMessage(err)`；TanStack Query 默认 retry/staleTime 已配。 |
| 设计系统 | `src/index.css`(oklch 令牌 + 图表色板) · `components/ui/*`(shadcn) · `PagePlaceholder` | 暖纸/青墨/琥珀；图表色 `--chart-1..5`；表单/卡片/下拉/徽章等已装。 |

**接一个新页的最小步骤**：① `pages/XxxPage.tsx` 写页面 → ② `nav.ts` 登记（管理者页加 `managerOnly:true`）→ ③ `App.tsx` 挂 Route（管理者页套 `RoleRoute`）。

## 3. 跨卡约定

- **接口调用**：一律走 `src/api/client.ts` 的 `api`（勿自建 fetch）；按域建 `api/<域>.ts` 放 TanStack Query hooks。
- **错误呈现**：`errorMessage(err)` 归一后端 `{error,detail}` / 422 校验数组；表单内联或 `toast.error`。
- **加载/空态**：列表用 `Skeleton`；整页用 `FullPageLoader`；占位用 `PagePlaceholder`。
- **角色**：管理者专属页同时做两层——`nav.ts` 标 `managerOnly` + 路由套 `RoleRoute`（后端亦强制，前端只是体验）。
- **契约变更**：后端改接口 → 重新 `npm run gen:api` → 类型驱动改前端（编译即提示破坏点）。
- **提交**：完成一单元即 commit（`type(web): 描述`，中文，无 co-author）；只 `git add image-web/<显式路径>`，禁 `git add -A`。
