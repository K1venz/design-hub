# gpt-image-2 中转站对比：诗云 API vs apinebula

- 日期：2026-05-29
- 调研人：Research
- 背景：设计中台图生图主业务需接 gpt-image-2，选型硬约束 = **稳定性 + 价格低 + 发票合规**
- 测试方法：同一冰箱商品图、同任务（图生图加中文促销文案）、同尺寸 1536×1024、medium 质量，两家各实测

## 一、结论速览

| 维度 | 诗云 API | apinebula |
|---|---|---|
| **实测扣费** | 待核控制台（按官方价折算 ≈¥0.44，实扣大概率更低） | **¥0.1/次**（控制台实扣，已确认）✅ |
| 出图质量 | 优秀 | 优秀（与诗云同源 gpt-image-2，肉眼无差） |
| 中文文案渲染 | ✅ 一次成功、零错字 | ✅ 一次成功、零错字 |
| 图生图 /images/edits | ✅ 支持 | ✅ 支持 |
| 返回格式 | b64_json | b64_json |
| 延迟（图生图） | 63–150s | ~90s |
| 协议 | OpenAI 兼容（New API 网关） | OpenAI 兼容（New API 网关） |
| **发票合规** | ✅ 宣称等保三级 + 增值税票 + 审计 | ⚠️ **未确认**，疑号池/逆向网关 |
| 稳定性 | 较稳（坏请求遇 429） | ⚠️ 实测撞「分组无渠道 503」 |

## 二、价格细节

**诗云**：按 token 实计（quota_type=0）。图生图 usage≈ in1054/out1756，按官方价折算 ≈¥0.44/张。
> 注：中转站普遍低倍率补贴，实扣大概率低于此估算 → **待核诗云控制台真实扣费**才能公平对比。

**apinebula**：价格页分两类，但有「分组陷阱」：
| 模型 | 价格页标价 | 所属分组 | 测试 key 能否用 |
|---|---|---|---|
| gpt-image-2 | $0.05/次(固定) | default / image2-business | ❌ key 不在该组，调用报 503 |
| gpt-image-2-vip / -pro | $0.10/次 | vip_image2 | ✅ 能用，**控制台实扣 ¥0.1/次** |

→ 价格页最便宜的 $0.05 版需要对应分组权限，普通 key 够不到；实际可用的是 **¥0.1/次** 的 vip 版。

## 三、风险提示（apinebula）

1. **合规存疑（最关键）**：分组命名充斥「自建号池」「逆向满血」「CODEX 自建号池」等，疑似号池/逆向网关。第三方逆向跑 gpt-image-2 大概率**开不了正规增值税票**，且违反平台 ToS、号池随时失效。
2. **稳定性差**：实测即撞 503 无渠道。号池类网关稳定性本就是雷。
3. **公司项目用途**：发票合规是硬约束 → apinebula 若客服无法开增值税票，**应出局**，便宜不能盖过合规。

## 四、给 PM 的建议

- **主力仍倾向诗云类有资质中转**（合规可控）；apinebula 价低但像逆向号池，适合个人/试用，不宜做公司生产主力。
- **两个待落实动作**（决定最终选型）：
  1. 问 apinebula 客服：能否开增值税专票？—— 生死线。
  2. 核诗云控制台：本轮 3 张图真实扣费 —— 才能与 apinebula ¥0.1 公平对比。
- 选型最终影响产品 → 建议在 image-issues 开条目把 owner 指给 PM 跟进。
