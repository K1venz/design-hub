# 出图工作台 v2 重做 · 电商 Listing 一键出图（前端设计稿）

> 日期：2026-06-04（2026-06-04 按 [ISSUE-0020] 后端对齐契约返工重写）
> 角色：前端设计师（image-web） · 状态：定稿待评审
> 契约源：`image-code/docs/superpowers/specs/2026-06-04-listing-image-generation-design.md` §4（以此为准）
> 参考：designkit.cn `product-kit` · 截图 `docs/screenshots/productkit-clean.jpeg`

## 一、背景与目标

现状：`/`（工作台）是项目列表，需先选/建项目 → 进 `/projects/:id` 的「出图/改稿/交付导出」tab 才能出图；
且同步阻塞、无进度（[ISSUE-0018]）。

目标：重做成 designkit `product-kit` 式 **「左配置 / 右画布」单页**——点进工作台**直接出图**。
后端已拍板走 **轻链路 `/listing/*`：multipart 直传 + 纯用户 prompt 直出（提示词是唯一杠杆）**，
**无项目、无资产库、无编排器**。本稿据此契约定义前端。

> 经 brainstorm 可视化对比「聊天框 vs 配置面板」，用户选定**配置面板**；再经 [ISSUE-0020] 后端对齐，
> 契约由 `asset_ids+project` 收敛为 `/listing/*` multipart。

## 二、信息架构与路由

| | 改造前 | 改造后 |
|---|---|---|
| `/`（工作台） | 项目列表表格，需选项目 | **直接是「商品套图」两栏页**（左配置 + 右画布） |
| `/projects/:id` | 出图/改稿/交付导出 3 tab | **删除** |
| 项目 / 选项目 / 隐式建任务 | 必经 | **彻底取消**（listing 链路无 project 概念） |
| 「＋ 新建任务」 | — | 纯前端**清空重来**（清图/清描述/清结果），无后端动作 |
| 客户 / 仪表盘 / 模型配置 / 用户管理 | 主导航项 | **本次不动**，入口收进头像菜单 |

MVP **不持久化** listing 历史（后端 §6.3 留了端口）。刷新即丢结果——记入"已知限制"（见第九节）。

## 四、数据契约（对齐后端 spec §4，**以后端为准**）

出图 = `POST /listing/generate`，`multipart/form-data`，Bearer：

| 表单字段 | 类型 | UI 来源 | 说明 |
|---|---|---|---|
| `images` | file × (1..3) | 产品原图上传 | 0 张或 >3 → 400，前端先行校验 |
| `prompt` | str | 「商品卖点&要求」文本框 | **核心入参**（直出唯一杠杆，落实 [ISSUE-0019] 第1点） |
| `ratio` | str（"1:1"…） | 「比例」下拉 | 后端映射 size；**前端不再单独传尺寸** |
| `n` | int 1..7 | 「张数」下拉 | 越界 → 400 |
| `modifiers` | str(JSON) | 「电商平台/国家地区/语言」等下拉 | 通用 key→value 袋子 |

返回 `{ "job_id": "<hex>" }`；进度 `GET /listing/{job_id}/events?access_token=<jwt>`（SSE，[ISSUE-0011] query 鉴权）：
逐张完成事件含 `url/seed/latency/cost`，另有 进度 / 全部完成 / 失败。

**`modifiers` 的前端处理（关键，呼应后端"增删下拉只改 key"）**：
前端维护一份 `MODIFIER_FIELDS`（如 `platform / region / language`）配置，渲染为下拉并序列化成
`modifiers` JSON。`ratio`、`n` 是独立结构字段，不进 modifiers。**以后加/减下拉 = 改 `MODIFIER_FIELDS`，
不动请求结构**。下拉枚举值由 PM 出（[ISSUE-0021]），前端按枚举渲染，未知值由后端 fail-fast。

配置栏字段最终清单：
- 产品原图：**multipart 直传 ≤3 张**（无"从资产库选"）
- 下拉 ×5：电商平台 / 国家地区 / 语言（→ modifiers）+ 比例（ratio）+ 张数（n）
- 商品卖点 & 要求：`prompt` 文本框（**无 "AI 帮写" 按钮**，后端 §2 列为非目标）

### 下拉枚举（用户确认首版 · 2026-06-04，PM 待在 [ISSUE-0021] 正式归档）

| 下拉 | 传输 | 取值（首版） |
|---|---|---|
| 电商平台 | `modifiers.platform` | 亚马逊 / 淘宝天猫1688 / 拼多多 / 京东 / Temu / TikTok Shop / 抖音电商 |
| 国家地区 | `modifiers.region` | 中国 / 美国 / 欧洲 / 俄罗斯 / 东南亚 |
| 语言 | `modifiers.language` | 英文 / 中文 / 俄语 / 西语 |
| 比例 | `ratio` | 1:1 / 3:4 / 9:16 / 16:9 |
| 张数 | `n` | 1..7（默认 6） |

- **比例 → size 映射（后端 §4.3）**：1:1→1024², 3:4→1024×1536, **9:16→1024×1536（竖图归并）**, **16:9→1536×1024（横图归并）**。gpt-image-2 仅三种真实尺寸，非方形按最近竖/横归并。
- ⚠️ **强一致约束**：后端 `prompt_composer` 的 `PromptModifierRegistry`（spec §5）必须覆盖以上每个
  `(平台/地区/语言)` 取值，否则出图当场 fail-fast 400。已回写 [ISSUE-0021] 通知 PM/后端对齐。

## 五、出图过程：async + SSE（解 ISSUE-0018）

1. 点「开始出图」→ 组 `FormData`（images + prompt + ratio + n + modifiers）→ `POST /listing/generate` 拿 `job_id`；
   右画布立刻铺 N 个"出图中"占位。
2. `EventSource('/api/listing/{job_id}/events?access_token=<jwt>')` 订阅：
   `进度 → 单张完成（url 替换占位，淡入）→ 全部完成 / 失败`。
3. 顶部细进度条 + 文案（"已出 3/6 张"）。
4. 容错：SSE 断线重连（I/O）；任务失败显式报错，不静默吞、不替默认值。

## 六、删除 / 保留 / 新增

**删除**：项目列表版 `WorkbenchPage`、`ProjectDetailPage`、`GenerateStudio`、`RevisionTab`(改稿)、
`ExportTab`(交付导出)、`ProjectPipeline`、同步 hook `useProjectGenerate`；
配置里的 `category/style/尺寸/subscene/family/tier` 字段；资产库相关 `AssetPickerInline`（不新建）。

**改造**：候选选稿「★评分 / 可用率 / 保留」**移除**——listing 链路不持久化、后端无评分，
改为 `ResultGallery` 的**逐张到达 + 直接下载**（满意即下，替代交付导出）。
故 `CandidateGrid` / `StarRating` 在新链路**不复用**（保留在仓库，老项目流如仍需另议）。

**新增**：见第三节组件表 + `useListingGenerate/useListingEvents` + 下载（单张/全部）。

## 八、视觉规范（designkit 风格 token）

- 背景 `#f6f4f1`；卡片 `#fff`；描边 `#ece8e2`；正文 `#1c1b1a`、次要 `#8a857e`。
- 圆角 12–16、结果图 16；柔投影 `0 24px 60px -22px rgba(60,50,40,.22)`。
- 主渐变 `#7c6cff → #a855f7 → #ff9a62`（CTA/进度条）；系统字体栈。
- **去营销小字与 emoji 腔**，文案克制。动效用 `motion`：出图中光环 + 进度条 + 逐张淡入。

## 九、已知限制 / 未决

- MVP 不持久化：刷新丢结果、无历史回看（后端留口子，后续接 DB）。
- 下拉枚举用户首版已确认（见 §四），前端据此渲染；PM 在 [ISSUE-0021] 正式归档 + 后端片段表须覆盖同值。
- 多图 edit 对 `n>1` 是否一次多张是后端实现期风险，但**不影响前端契约**（前端只认 SSE 逐张事件）。
- 「爆款图复刻」本期仅占位（点击"敬请期待"），不实现。
