# 出图工作台 v2 重做 · 商品套图配置面板（设计稿）

> 日期：2026-06-04 · 角色：前端设计师（image-web）
> 状态：定稿待评审 · 参考：designkit.cn `product-kit` 页 + bytedance/deer-flow 前端
> 参考截图：`docs/screenshots/designkit-home-ref.jpeg`、`productkit-clean.jpeg`

## 一、背景与目标

现状：`/`（工作台）是一张**项目列表表格**，必须先选/建项目 → 进 `/projects/:id` → 在「出图工作台 / 改稿 / 交付导出」三个 tab 里才能出图。"出图前还要先选项目" + 同步阻塞出图无进度（见 [ISSUE-0018]），体验差。

目标：把工作台重做成 **designkit `product-kit` 式的「左配置 / 右画布」单页**——点进工作台**直接出图，不再选项目**；出图过程实时可感知；满意即下载。视觉对齐 designkit（暖白、留白、大圆角、柔投影），去 AI 腔、去多余小字。

> 决策依据：经 `/__brainstorm` 可视化对比「方案 A 聊天框」vs「方案 B 配置面板」，用户选定 **B**。

## 二、信息架构与路由

| | 改造前 | 改造后 |
|---|---|---|
| `/`（工作台） | 项目列表表格，需选项目 | **直接是「商品套图」两栏页**（左配置 + 右画布） |
| `/projects/:id` | 项目详情：出图/改稿/交付导出 3 tab | **删除**（出图提升为工作台本体；改稿/导出取消） |
| 选项目这一步 | 必经 | **取消**；「＋ 新建任务」隐式建 project |
| 客户 / 仪表盘 / 模型配置 / 用户管理 | 主导航项 | **本次不动**，入口收进头像菜单 / 次级位置 |

**「任务（task）」= 一次出图会话**，底层仍对应一个后端 `project`，但对用户透明：进页面即落到当前/最近任务，点「＋ 新建任务」开新会话。项目概念退到后台。

## 三、页面结构与组件拆分

整页为**固定高、三段横向布局**（顶栏 + 左导航 + 配置栏 + 右画布）：

```
┌─ 顶栏：出图 logo ｜＋新建任务 ……………………………… 头像 ─┐
├──────┬─────────────────┬──────────────────────────┤
│ 左导航 │  配置栏(392px)    │  右画布(flex)              │
│ 商品套图│  产品原图(上传/资产库)│  商品套图 · 候选选稿        │
│ 爆款图 │  生成设置(8下拉)   │  ┌──┬──┬──┐  ★评分/可用率   │
│ 复刻  │  描述&要求(prompt) │  │  │  │  │  保留 / 下载     │
│      │  [开始出图·成本]   │  └──┴──┴──┘  出图中占位+进度  │
└──────┴─────────────────┴──────────────────────────┘
```

组件（每个单一职责、可独立理解/替换）：

| 组件 | 职责 | 来源 |
|---|---|---|
| `WorkbenchPage`（重写） | 两栏页外壳 + 任务态管理 | 替换原项目列表 |
| `WorkbenchRail` | 左导航：商品套图(active) / 爆款图复刻(敬请期待) | 新增 |
| `ProductSetConfigPanel` | 配置栏：上传 + 8 下拉 + 描述 + 开始出图 | 新增（吸收 GenerateStudio 配置部分） |
| `AssetPickerInline` | 「从资产库选」内联面板（资产库入口） | 新增（复用 `useAssets`） |
| `ResultCanvas` | 右画布：候选选稿 + 进度 + 下载 | 新增（包 `CandidateGrid`） |
| `useAsyncGenerate` / `useGenerationEvents` | 异步出图 + SSE 进度订阅 | `src/api/generation.ts` 新增 |
| 复用：`CandidateGrid` `ImageThumb` `StarRating` `select-rich` `GradientButton` `visual/*` | 选稿/评分/下拉/渐变按钮/配饰 | 保留 |

## 四、配置项 → 数据契约

配置栏字段（左→右、上→下），及其与后端契约的映射：

| UI 字段 | 取值示例 | 后端字段 | 状态 |
|---|---|---|---|
| 产品原图（上传/资产库） | 最多 3 张 | `asset_ids: number[]` | 已有 |
| 电商平台 | 亚马逊 / 淘宝 / TikTok / 独立站 | `platform` | **新增** |
| 国家地区 | 美国 / … | `region` | **新增** |
| 语言 | 英文 / 中文 | `language` | **新增** |
| 比例 | 1:1 / 3:4 / 16:9 | `ratio` | **新增** |
| 品类 | 食品 / … | `category` | 已有 |
| 风格 | 清新自然 / … | `style` | 已有 |
| 尺寸 | 1024² / … | `width` `height` | 已有 |
| 数量 | 6 张 | `n` | 已有 |
| 描述 & 要求 | 自由文本（✨AI 帮写） | `prompt` | **新增**（[ISSUE-0019]） |

**从 UI 移除**（不再暴露给用户）：`subscene`（子场景）、`family`（模板族）、`tier`（档位）。

> 备注：「尺寸」与「比例」并存（用户确认保留），比例=长宽比、尺寸=分辨率，二者独立。

## 五、出图过程：async + SSE（解 ISSUE-0018）

废弃同步阻塞出图（`POST /projects/{id}/generate` 一直 await）。改为：

1. 点「开始出图」→ `POST /generate/async`（Bearer）拿 `job_id`，右画布立即出现 N 个「出图中」占位。
2. `EventSource('/api/generate/{job_id}/events?access_token=<jwt>')` 订阅进度（token 走 query，原生 EventSource 不能带头，见 [ISSUE-0011]）：
   `task_started → model_called → image_generated（逐张到达，替换占位）→ task_completed`。
3. 顶部细进度条 + 文案（"正在生成第 3/6 张…"）。完成后拉候选列表。
4. 错误：SSE 断线重连（I/O 容错）；任务失败显式报错，不静默吞。

> 后端 async + SSE 能力已就绪（[ISSUE-0018] 内 QA 已验全序列），前端只需接入。

## 六、删除 / 保留 / 新增清单

**删除**：项目列表版 `WorkbenchPage`、`ProjectDetailPage`、`GenerateStudio`（拆分吸收）、`RevisionTab`（改稿）、`ExportTab`（交付导出）、`ProjectPipeline` 等仅服务于项目列表/详情的组件。同步出图 hook `useProjectGenerate`。

**保留**：`CandidateGrid` `ImageThumb` `StarRating`、`select-rich.tsx`、`visual/*`、`AppLayout`（头像菜单承接管理页入口）、客户/仪表盘/admin 各页与路由。

**新增**：见第三节组件表 + async/SSE hooks + 候选图「下载」动作（满意即下，替代交付导出）。

## 七、后端契约缺口（开 image-issue 给 Dev）

用户已确认"前端先做、后端自行适配"。前端将按本设计的新契约提交，需后端：

1. `ProjectGenerateRequest` / `/generate/async` / `/generate/cost-preview` **新增** `platform`、`region`、`language`、`ratio`、`prompt`（自由文本，拼入 gpt-image 提示）。
2. **放宽/移除** `subscene`、`family`、`tier` 的必填约束（UI 不再传）。
3. `AssetOut` 可选 `description`（资产库回显，[ISSUE-0019] 第 2 点）。
4. **隐式建任务**：现状建项目需先选客户+填名。"＋新建任务"要无感创建，需后端支持「快速任务」——自动挂默认客户、免填名（或前端首次出图时静默用默认客户建项目）。取值方案待定。

→ 汇总成一条新 issue（扩展 [ISSUE-0019]）指给开发。

## 八、视觉规范（designkit 风格 token）

- 背景 `#f6f4f1`（暖白）；卡片 `#fff`；描边 `#ece8e2`；正文 `#1c1b1a`、次要 `#8a857e`。
- 圆角：卡片/输入 12–16、候选图 16；柔投影 `0 24px 60px -22px rgba(60,50,40,.22)`。
- 主渐变（CTA/强调）：`#7c6cff → #a855f7 → #ff9a62`；保留态绿 `#0f9d72`、评分星 `#f5a623`。
- 字体系统栈（PingFang/雅黑）；**去多余营销小字与 emoji 腔**，文案克制。
- 动效沿用 `motion`：出图中光环/进度条、逐张到达淡入。

## 九、未决 / 风险

- 各下拉的**完整枚举**（电商平台/国家地区/语言/比例/品类/风格清单）需与后端/PM 对齐取值。
- 新字段后端就绪前，前端出图会失败——前端可先用现契约联调骨架，新字段待后端跟进（用户负责后端）。
- 「爆款图复刻」本期仅占位（点击提示"敬请期待"），不实现。
