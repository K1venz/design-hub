# 出图工作台 · 需求单 + 出图选稿 合并设计（定稿）

经多轮 demo（`/__demo/merge`）与用户确认定稿。本文记录布局、数据映射与后端缺口。

## 目标
项目详情里把「需求单」「出图与选稿」两个 tab 合并成一个 **「出图工作台」** tab，
布局参照美图设计室（designkit）的「大聊天框创意 console」，动画沿用 21st.dev `ai-gen`
（渐变发送键、出图中加载动画）。要求：干净、去 AI 腔、傻瓜式、打开即用。

## 布局（自上而下，单列）
1. **Hero 大聊天框**（居中、留白充足、圆角 28、柔和投影）
   - 标题「想要什么样的图？」
   - **玩法胶囊**：换背景 / 场景图 / 多角度（= 子场景 S1 / S3 / S4）
   - 大 textarea（描述画面）+ 底部工具条：左「添加参考图」/图标；右「成本预估 ¥x」+ **渐变开始出图**
   - 下方「⚙ 高级设置」折叠（默认收起，全有默认值——不展开也能出图）
2. **高级设置（展开）**：7 个 rich 下拉（`select-rich.tsx`，右侧勾选指示）——
   子场景 / 模板族 / 品类 / 档位 / 风格 / 数量 / 尺寸
3. **参考图（可选）**：横向滚动图片行；点图＝选作图生图源（asset_ids）+ 回显参考提示进聊天框
4. **候选选稿**：出图任务的候选图（复用 `CandidateGrid`：评分 / 可用率 / 保留）
5. **出图中**：点开始出图后显示 ai-gen 加载动画（旋转光环 + 渐变进度条 + 轮播文案）

## 数据映射（接现有后端契约，前端不改后端）
| UI | 绑定 |
|---|---|
| 聊天框文字 | `brief.copy_text`（载入预填、开始出图时 `useUpsertBrief` 持久化，保留其余 brief 字段） |
| 玩法胶囊 | `GenerateConfig.subscene`（S1/S3/S4），与高级里「子场景」同步 |
| 高级 7 下拉 | `GenerateConfig` 的 subscene/family/category/tier/style/n/width+height（尺寸预设拆 w×h） |
| 参考图板 | `useAssets(projectId)`；选中项 → `GenerateConfig.asset_ids` |
| 开始出图 | `useProjectGenerate(config)`；isPending 时显示加载动画 |
| 成本预估 | `useCostPreview` |
| 候选选稿 | `useProjectJobs` + `CandidateGrid`（沿用既有选稿/评分逻辑） |

## 关键决策 / 与 demo 的差异
- 玩法胶囊 **3 个**（对齐真实 3 个子场景），去掉 demo 里的「风格化」（无对应 subscene）。
- 高级下拉补 **风格**（GenerateConfig 必填 style），故 7 个而非 demo 的 6 个。
- 档位/子场景下拉：显示中文、value 用后端枚举（draft/standard/refine、S1/S3/S4）。

## 后端缺口（前端只能近似，开 image-issue 给 Dev）
1. **自由 prompt 未进出图**：`GenerateConfig` 无自由文本字段，聊天框文字目前仅存 `brief.copy_text`，
   不直接驱动出图。若要「描述真正影响出图」，需后端在出图入参加 prompt/notes 字段。
2. **素材无 prompt 字段**：点参考图「回显对应 prompt」在真数据下无每图 prompt 可回显，
   现以模板提示词近似（如“参考产品图#3 的构图与质感”）。如需每图独立 prompt，需后端给 asset 加字段。
