> 日期：2026-06-10 · 角色：frontend-b · 状态：方案待三方对，**不动代码**
> 依据：PRD §3.13（PM 1bad38e）· 复用优先铁律（商品套图整套为参照实现）
> 沿用：比例/张数1/¥0.40/FOOD/平台语言收窄 全不变

## 〇、导航：爆款复刻挪最左 + 转活页

- `WorkbenchRail` ITEMS 调序：**爆款图复刻第一位、商品套图第二**；rail 改为**路由驱动**（NavLink）：`/` = 商品套图工作台（**默认进套图**，用户已拍）、`/clone` = 复刻工作台，active 态跟路由。
- 死按钮转活：去掉 `enabled:false` + toast「敬请期待」。
- `/clone` 复用 `WorkbenchLayout`（顶栏+新建任务+rail），新 `CloneWorkbenchPage` 与 WorkbenchPage 平级。

## 一、复刻配置栏（CloneConfigPanel，骨架同 ListingConfigPanel）

```
产品原图（你的商品 · 必传）
  [上传区 A]  说明：将原样保真出现在成品里
参考爆款图（想复刻的模板 · 必传）
  [上传区 B]  说明：只借它的结构/风格，模板上的产品与文案不会出现在成品
  ── 合计 ≤3 张（A≥1、B≥1；A+B≤3，两区上限联动）──
生成设置   电商平台 / 语言 / 比例（沿用收窄）
复刻程度（两张单选卡）
  ◉ 参考风格   学整体风格·构图·调色，自动重构场景
  ○ 高度复刻   照搬模板版式结构，替换为你的产品
统一复刻要求   [textarea 复用 prompt 框]（如：文案统一中文 / 只换商品其余不变）
[ 开始复刻   约 ¥0.40 · 1 张 ]
```

要点：
- **双上传区语义钉死（本页最大 UX 风险=两区传反）**：区头主标签+一句白话说明（上文），上传区 A/B 都复用现成 `ImageUploader`；**两区上限联动**：各自 `max = 3 - 另一区已传数`（A≥1、B≥1、A+B≤3，PRD 配比默认产品1+参考1~2 归 dev 终值）。CTA 在任一区为空时禁用。
- **复刻程度**：两张单选卡（标题+说明，非裸 radio——两档语义差异大、说明文案是用户理解保真口径的唯一入口）。**默认档提案=参考风格**（低风险档；默认档是产品决策，三方对/用户可改）。
- **统一复刻要求**：复用 prompt textarea、改标签为「统一复刻要求」+ placeholder 示例（"文案统一中文 / 模特不变只换商品"）。⚠️ **必填性待对**：竞品此项选填；现行 listing 后端 prompt 必填 fail-fast——「复刻档 prompt 是否放宽为可选」归 dev 契约拍（见依赖 #4）。
- 张数固定 1（用户已拍）、无步进器；CTA「开始复刻 约 ¥0.40 · 1 张」。

## 二、结果与历史

- 结果画廊：1 张 → 复用现行**不分组**画廊（占位/淡入/下载/失败槽全沿用）；SSE 走同一 useListingEvents。
- 历史：复刻 job 进同一历史列表；若 detail 带 `clone_mode` 字段则详情页加「复刻·参考风格/高度复刻」徽标（依赖 dev D 变更点，没有就不显示、零阻塞）。
- 「新建任务」：在 /clone 页同样清空（newTaskBus 既有机制，CloneWorkbenchPage 订阅）。
