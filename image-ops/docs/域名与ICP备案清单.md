## 二、ICP 备案材料清单（接入商=火山引擎）

### 前置决策（用户拍）
1. **主体类型：强烈建议企业主体**。toC 商用收费（积分制）属经营性质，个人备案不可商用；后续若需经营性 ICP 许可证（ICP-B/EDI）也必须企业主体。
2. **网站名称**：拟用「实朴电商图片工作站」——3 字以上、不含敏感词，预计可过；管局可能要求与经营范围相关。

### 企业备案材料（提交前备齐）
- [ ] 营业执照（统一社会信用代码，彩色原件照/扫描）
- [ ] 法定代表人身份证（正反面）
- [ ] 网站负责人身份证（正反面）+ 实名手机号 + 邮箱（可与法人同一人）
- [ ] 网站负责人**APP 人脸核验**（火山引擎备案 APP/小程序，替代旧幕布照）
- [ ] 域名证书（注册商后台下载）
- [ ] **域名实名认证主体 == 备案主体**（企业名义注册域名，个人名义注册需先过户）
- [ ] 服务器满足备案条件：火山引擎**包年包月** ECS、剩余有效期 ≥3 个月（现按量/短期的话需先转包年包月——部署机现状待核）
- [ ] 网站服务内容说明（电商图片 AI 生成工具；AIGC 属性管局可能问询，准备一段服务说明）
- [ ] 前置审批：图片工具类一般**无**前置审批项（非新闻/出版/药品等）

### 流程与时长（最长杆，宜最先启动）
1. 注册域名 + 域名实名认证：1-3 天
2. 火山引擎备案系统提交 + 初审：1-2 工作日
3. 短信核验 + 管局审核：**7-20 个工作日**（上海管局通常 1-2 周）
4. 拿备案号 → 页脚挂备案号（7.E 法务页一并做）
- ⚠️ 审核期间该域名**不能解析开放访问**；现 IP 直连可继续内测，互不影响。
- 并行线：**算法备案/生成式 AI 标识（gate 7.B）走网信办，是另一条线**，与 ICP 并行启动（PM 细化）。

### 用户必须亲自做的（无法代办）
购买域名（实名）/ 备案提交与人脸核验 / 全部付费动作。
