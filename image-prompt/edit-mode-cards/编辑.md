# 编辑模式卡(二次编辑 · 两档)

> **第六类卡**:编辑模式(ISSUE-0040)。设计决策记录见 [../二次编辑-编辑模式草案.md](../二次编辑-编辑模式草案.md)。
> 协议全沿物化块铁律:产品中性 / 物化块=单一事实源,dev `EditModeRegistry{edit_mode→块}` 硬编码副本+程序化逐字核对(pytest 自动闸) / 改块=同步+核对+QA 复验 / 块末尾无多余换行。

```yaml
模式: 编辑(二次编辑,独立模式;不引图型卡、不支持 overlay_texts——用户拍,改图上字=对卖点图 full 重做)
档位枚举(registry key = edit_mode 列值): delta(微调,默认) | full(重做)
输入契约(已锁): 第 1 张 = 被编辑源图(编辑基底,上一轮产出,按 source_image_key 读 generate 桶);其后 1..3 张 = 迭代链根原始产品图(产品保真锚,零代损耗,读 uploads 桶)。喂序=契约(dev 保序),"其后的图"措辞覆盖可变锚张数、零槽位。
组装序: 编辑模式块(自含产品保真) → 用户编辑指令(必填) → modifier 片段(delta 继承父 job 叠新/full 可改)
不注入: 品类保真块(其"只重绘产品周围"与 delta 锚定语义冲突,编辑块自含保真)、图型卡、风格卡、父 prompt(Q-β:源图即其执行结果,文本二传必与本轮指令打架)

失真命门:   # 按严重度
  - 【最高优先级】多轮迭代产品漂移(QA D2/TC-05):失真不可逆,锚上一轮=漂移逐轮叠加 → 产品保真锚**永远取链根原始产品图**,每轮从零失真事实源重建。
  - 改动外溢(delta):模型把"换背景"做成"重做整张" → 全锚定句权重最前、"未点名一概不动"收尾。
  - 越权改产品:用户指令要求改产品本体 → "产品不变"在前压制(产品级改动超出二次编辑 scope)。
  - 编辑中冒出多余文字/水印 → full 块显式禁;delta 由"未点名不动"覆盖。

quality 档: 统一默认档(编辑不压字,无 high 需求)。
```

## 物化块 ×2(compose_prompt 注入用 · 单一事实源;dev 按 edit_mode 选块)

### delta · 微调(默认)

```text
编辑·微调：本次是对已生成图的定向微调。第 1 张为当前画面（被编辑基底）——构图、场景、光线、配色与一切未被下方修改要求点名的元素全部保持与它一致，不重新设计；其后的图为产品原图——画面中产品的外形、包装与所有文字以产品原图为准逐字逐细节保留、一个字一个像素都不改，不被当前画面中产品的任何失真带偏。仅按下方修改要求做最小幅度的定向调整，修改要求未提到的一概不动。
```

### full · 重做

```text
编辑·重做：本次基于已生成图重新创作。第 1 张为此前画面（仅作方向参考，不必沿用其构图）；其后的图为产品原图——画面中的产品只能是产品原图中的那个产品，其外形、包装与所有文字以产品原图为准 100% 原样保留、不改一字。请按下方新要求重新设计场景、构图与光线：画面如真实相机拍摄、自然光影、产品与台面有真实接触阴影，不堆砌与产品无关的道具，不出现水印与多余文字。
```
