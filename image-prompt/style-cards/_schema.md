# 风格卡 Schema(作者指南)

> 风格卡 = 注入给 agent 的「这次要什么调性/色彩/光的情绪」。
> 比品类卡轻:只管**审美**,不管产品物性(物性归品类卡)。一张卡对应一个 `domain/enums.py: Style`。
> 当前已建:[fresh-natural](./fresh-natural.md)。

```yaml
style: <对应 Style 枚举,如 FRESH>
色卡: <具名色/HEX,3 色以内>
光色情绪: <光的色温与情绪,如"明亮自然光、清透暖白";只管色温,光的方向硬度归品类卡>
情绪基调: <氛围词,如"清新通透、居家治愈">
修饰词: <2-3 个整图调性词;严禁混入宪章禁词>
反 AI 提示: <这个风格特别容易翻车成什么 AI 味,怎么避>
```

## 两条原则
1. **色温归风格、光向归品类**:宪章组装时把"品类光型 + 风格光色"拼起来,不互相覆盖(沿用现有 orchestrator 的拼接约定)。
2. **修饰词不许碰禁词**:风格再"高级"也不准用"大片感/电影级/8K"(那是 AI 假感来源,见宪章 §2.3)。
