# 复刻模式卡(爆款图复刻 · 两档)

> **第五类卡**:复刻模式,独立于图型卡(复刻不叠图型卡,模板已决定构图;plan/n 不参与)。设计决策记录见 [../爆款复刻-两档指令草案.md](../爆款复刻-两档指令草案.md)。
> 协议全沿物化块铁律:产品中性 / 物化块=单一事实源,dev `CloneModeRegistry{档位→块}` 硬编码副本+程序化逐字核对 / 改块=同步+核对+QA 复验 / 块末尾无多余换行。

```yaml
模式: 复刻
档位枚举(中文 key): 参考风格 | 高度复刻
输入契约(已锁): 产品图 ==1(喂图第 1 张) + 爆款参考图 1~2(其后);固定序=契约(dev 保序传递)——块内角色指认依赖此序,零槽位纯静态
组装序: 保真块(品类卡) → 复刻档位块(含角色指认) → 用户统一要求(选填,可为空) → platform/region/language 片段

失真命门:   # 双向污染三条(#537/#538),两档块都显式防御,QA 视觉核三条全验
  - 【最高优先级】竞品泄漏:参考图中的竞品产品/品牌标识/文字泄进输出(法律+品牌双风险)。
  - 产品被带歪:用户产品的外形/包装被参考图原产品"同化"。
  - 文案错位:参考图的营销文案被糊到用户产品/包装上。

文案规则(0038 兜底,档2 块内写死): 用户统一要求里显式给图上文案→引号原文逐字呈现;未给→画面不出现任何营销文字,绝不保留模板原文、绝不让模型自编字。

与保真块相容: |
  保真块"上传参考图里的产品"在双图下的歧义,由档位块开头的角色指认句消解("第 1 张为用户产品图,产品保真以它为准")。
  档2"照搬版式/道具位置关系"后到、收窄保真块"少量衬托道具"句;若 QA 回归发现保真块"严禁堆砌无关物"压过模板道具结构,再调措辞。

UI 投影: 两档单选卡白话说明文案见群 #549(已交 frontend,与块行为逐条对应;含"场景细节可能略有差异"预期管理句)。
```

## 物化块 ×2(compose_prompt 注入用 · 单一事实源;dev 按档位选块)

### 档 1 · 参考风格

```text
复刻·参考风格：本次有两类参考图——第 1 张为用户产品图，产品保真以它为准；其余为爆款风格参考图，仅用于学习其整体风格调性、色彩氛围、光影感觉与构图思路，按这种风格为该产品重新设计一个合适的场景。风格参考图中的产品、品牌标识与所有文字一律不出现在画面中；画面中的产品只能是用户产品图中的那个产品，其外形、包装与文字原样保留、不被风格参考图带偏。
```

### 档 2 · 高度复刻

```text
复刻·高度复刻：本次有两类参考图——第 1 张为用户产品图，产品保真以它为准；其余为爆款版式参考图，请照搬其视觉结构：布局、机位、景别、道具位置关系与画面节奏，把版式参考图中产品所在的位置替换为用户产品图中的那个产品（占位、比例与视角对应），场景细节允许略有差异。版式参考图中的原产品、品牌标识与营销文案一律不出现在画面中；用户产品的外形、包装与文字 100% 原样保留、一字不改，绝不被版式参考图中的产品样式带偏。若下方用户要求中明确给出图上文案，仅以引号内原文逐字呈现；否则画面中不出现任何营销文字。
```
