# 复刻模式卡(爆款图复刻 · 两档)

> **第五类卡**:复刻模式,独立于图型卡(复刻不叠图型卡,模板已决定构图;plan/n 不参与)。
> 设计决策记录见 [../爆款复刻-两档指令草案.md](../爆款复刻-两档指令草案.md);「完全复刻」改版设计稿见 [../../docs/superpowers/specs/2026-06-15-clone-full-replicate-redesign-design.md](../../docs/superpowers/specs/2026-06-15-clone-full-replicate-redesign-design.md)。
> 协议全沿物化块铁律:产品中性 / 物化块=单一事实源,dev `CloneModeRegistry` 硬编码副本+程序化逐字核对(pytest 自动闸) / 改块=同步+核对+QA 复验 / 块末尾无多余换行。

```yaml
模式: 复刻
档位枚举(中文 key): 参考风格 | 完全复刻   # 2026-06-15 高度复刻→完全复刻(界面标签 + clone_mode 值同步改名)
输入契约(已锁): 产品图 ==1(喂图第 1 张) + 爆款参考图 1~2(其后);固定序=契约(dev 保序传递)——块内角色指认依赖此序

overlay_texts(完全复刻专属,选填):
  口径: 1~2 条 / 每条 ≤12 字,沿卖点图同口径常量、不放宽(用户拍 #844)
  适用档: 仅「完全复刻」可带;「参考风格」带 overlay → 显式 400(coordinator #847,fail-fast 不静默)
  注入格式(同卖点图,dev 照拼): 全角引号包裹、顿号分隔 —— 「{c1}」、「{c2}」

组装序: 保真块(品类卡) → 复刻档位块(含角色指认;完全复刻+overlay 时块内 {overlay_texts} 槽运行时填充) → 用户统一要求(选填,可为空) → platform/region/language 片段

档块选择(dev 按"档位 + 有无 overlay_texts"选块,同 ImageTypeRegistry 卖点逻辑):
  参考风格               → 参考风格块(单块,画面无营销文字)
  完全复刻 + overlay 缺省 → 完全复刻·无字版(纯风格复制,画面无文字)
  完全复刻 + overlay 1~2 → 完全复刻·有字模板({overlay_texts} 槽填充,静态部分逐字核对)

失真命门:   # 双向污染(#537/#538) + 完全复刻新增字样维度,QA 视觉核全验
  - 【最高优先级】竞品泄漏:参考图的竞品产品/品牌标识/文字(含大标题、卖点角标、banner 原文)泄进输出(法律+品牌双风险)。完全复刻"贴版式"更易把参考原文一并搬上 → 块内显式"只贴文字样式、内容换用户文案、绝不照抄参考图文字"。
  - 产品被带歪:用户产品的外形/包装被参考图原产品"同化"。
  - 图上字糊字/typo(0038):图上文字只来自 overlay_texts、引号 verbatim 锁定;无 overlay 则画面零文字、绝不让模型自编。
  - 字样没复刻(完全复刻有字模板):文案退化成中性字体 ≠ 参考图爆款字样 → 块内"字体/字号/字重/颜色/位置/banner/角标照参考图"。

文案规则(0038 兜底,完全复刻块内写死): overlay_texts 给→按参考图字样 verbatim 渲染;未给→画面零营销文字,绝不保留参考图原文、绝不让模型自编字。
quality 档: 完全复刻·有字模板建议 quality=high(宪章 §2.1:含图上文字的图);参考风格 + 完全复刻·无字版用默认档。

与保真块相容: |
  保真块"上传参考图里的产品"在双图下的歧义,由档块开头角色指认句消解("第 1 张为用户产品图,产品保真以它为准")。
  完全复刻"完整复制画面风格/版式"后到、收窄保真块"少量衬托道具/简洁背景"句(贴爆款版式优先);产品保真句不受影响(产品仍 100% 锁用户图)。

UI 投影: 「完全复刻」白话 desc 交 frontend-b verbatim 折入(与块行为逐条对应);「参考风格」desc 不变。

⚠️ dev 复用边界(spec §四"复用卖点图那套"的准确含义):
  复用的是**机制**——{overlay_texts} 槽 + verbatim 注入格式(「{c1}」、「{c2}」)+ 2×12 常量 + 无字/有字双块按 overlay 选块逻辑;
  **不是**把 CloneModeRegistry 指向卖点图块。完全复刻·有字模板块文本**必须独立**:卖点图="简洁现代无衬线字体"(固定中性),完全复刻="按参考图同款字样"(复刻参考)——语义相反,块不可共用。
```

## 物化块 ×3(compose_prompt 注入用 · 单一事实源;dev 按"档位 + 有无 overlay_texts"选块)

### 档 1 · 参考风格

```text
复刻·参考风格：本次有两类参考图——第 1 张为用户产品图，产品保真以它为准；其余为爆款风格参考图，仅用于学习其整体风格调性、色彩氛围、光影感觉与构图思路，按这种风格为该产品重新设计一个合适的场景。风格参考图中的产品、品牌标识与所有文字一律不出现在画面中；画面中的产品只能是用户产品图中的那个产品，其外形、包装与文字原样保留、不被风格参考图带偏。
```

### 档 2 · 完全复刻 · 无字版(overlay_texts 缺省)

```text
复刻·完全复刻：本次有两类参考图——第 1 张为用户产品图，产品保真以它为准；其余为爆款参考图，请最大程度完整复制其画面风格：构图、机位、景别、光影、配色、背景与版式节奏都照参考图来，把参考图中产品所在的位置替换为用户产品图中的那个产品（占位、比例与视角对应）。参考图中的原产品、品牌标识与所有文字（大标题、卖点角标、banner 等）一律不出现在画面中，画面中不出现任何营销文字、标贴与水印，也不要自行编造任何文案。用户产品的外形、包装与文字 100% 原样保留、一字不改，绝不被参考图中的产品样式带偏。
```

### 档 2 · 完全复刻 · 有字模板(overlay_texts 1~2 条;`{overlay_texts}` = 注入槽,按上方注入格式填充;静态部分逐字核对)

```text
复刻·完全复刻（带文案）：本次有两类参考图——第 1 张为用户产品图，产品保真以它为准；其余为爆款参考图，请最大程度完整复制其画面风格：构图、机位、景别、光影、配色、背景与版式节奏都照参考图来，把参考图中产品所在的位置替换为用户产品图中的那个产品（占位、比例与视角对应）。图上文字只复刻参考图的呈现样式——字体、字号、字重、颜色、位置、banner 与角标的排版方式照参考图，但文字内容一律换成下方给定文案、绝不照抄参考图上的任何文字。
图上文案，逐字呈现、一字不增不减不改、不翻译，按参考图同款文字样式排版：{overlay_texts}。除该文案外，画面中不出现任何其他文字、标贴与水印；参考图中的原产品、品牌标识与原有文案一律不出现在画面中。用户产品的外形、包装与文字 100% 原样保留、一字不改，绝不被参考图中的产品样式带偏。
```
