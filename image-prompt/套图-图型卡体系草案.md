## 1. 定位:第四类卡——图型卡(image-type card)

现有三层指令架构(宪章 §3)不动,**新增一个正交维度**:

```
[宪章]                永注:角色/铁律/输出契约
 + [品类卡]           按 category:产品是什么、怎么保真(现=通用产品保真块)
 + [风格卡]           按调性:色卡/光色/情绪
 + [图型卡] ← 新增    按图型:这一张图的「用途+构图范式」(白底/场景/卖点/补位)

## 2. MVP 四张图型卡

每张卡字段:用途 / 定调句模板 / 构图范式 / 必含要素 / 禁止项 / 与保真块相容注意。
末尾各带 ```text 物化块(同品类卡协议:单一事实源,dev 硬编码副本+逐字核对)。

### ① 白底主图卡(white-base)
- 纯白背景(电商主图合规)、产品居中、占画面主体、无道具无场景、可多角度呈现细节。
- 🔑 关键张力:**白底≠抠图悬浮**——仍要真实摄影感:产品与台面有真实接触阴影、柔和的自然投影、光有方向,防"贴图感/悬浮感"。
- 与风格卡关系:白底图**跳过风格卡**(白底无风格调性,注入反而引入杂色)。

### ② 场景图卡(scene)
- 产品的真实生活使用场景(环境叙事:厨房/客厅/茶几/办公桌…按产品相关选择)。
- 场景必须与产品相关(承通用块「不堆无关物」,场景图是最容易堆杂物的图型,要显式收)。
- 🔓 设计点 Q1:竞品含"人物搭配"。**建议 MVP 场景无人**——人物生成=手/脸失真高风险,且现行通用块"画面禁止人物";人物场景后置。

### ③ 卖点图卡(selling-point)
- = 当初 MVP 砍掉的**卖点层受控回归**:核心卖点短语压图 + 产品细节特写。
- 文字铁律(宪章 §2.1):卖点短语**引号锁定 verbatim**、限 1-2 条短句(中文字越多越糊)、显式标位置/字号/颜色、档位 quality=high。
- 🔓 设计点 Q3:卖点文案来源——用户"卖点&要求"输入里 agent 摘 1-2 条最强 vs 用户显式标哪条上图。

### ④ 智能补位卡(smart-fill)
- 竞品="对比图/尺寸图等,根据商品智能匹配"。
- 🔓 设计点 Q2 两个选项:
  - A. **受控自由度**:从[细节特写/规格示意/多件组合/包装多面]白名单中按产品选最合适(禁选与产品无关的型);
  - B. **MVP 固定为"细节特写图"**——最稳、零智能匹配风险,真"智能"后置(与 PM 把"智能匹配"推 backlog 同节奏)。
- 倾向 B(YAGNI),三方对拍。

## 3. 组装序(保真块 × 图型卡 × 用户文本 × modifier)

套图 = n 张图、**每张独立 compose**(dev 编排,每张带图型标签):

```
[产品保真块(category,现行不动)]   ← 永远最前,北极星1;全图型生效=竞品没有的差异化
→ [图型卡块(本张的图型)]          ← 提供定调句(宪章 §4 第1条),紧跟保真块
→ [用户卖点&要求文本]
→ [platform/region/language 片段]  ← 现行 modifier 不动
```

- 保真块位置已验证(QA #196/#198),不动。
- 卖点图在此序上额外注入文字层(verbatim 锁定)。
- 白底图跳过风格卡;其余图型正常走风格卡(若启用)。
