# 图型卡 Schema(作者指南)

> 图型卡 = **第四类卡**,管「这一张图的用途+构图范式」,与品类卡(管产品保真)**正交**。
> 一张卡对应一个图型枚举(PRD §3.12.14,plan dict 的 key)。MVP 3 张:[白底](./白底.md) / [场景](./场景.md) / [卖点](./卖点.md);「智能补位」随智能匹配 backlog。
> 体系草案与设计决策记录见 [../套图-图型卡体系草案.md](../套图-图型卡体系草案.md)。

## 铁律(全部沿品类卡协议)
1. **产品中性**(#366 教训):写"产品的细节特写",绝不写任何具体产品专属描述。
2. **物化块 = 单一事实源**:每卡末尾 ```text 块,dev `ImageTypeRegistry{图型→块}` 硬编码副本;**改块 = @dev 同步常量 + 程序化逐字核对 + QA 复验**。
3. 物化块**末尾不带多余换行**(dev compose 分隔符约定,#466)。
4. 模板槽位(如卖点卡 `{overlay_texts}`):逐字核对覆盖静态部分,槽位由 dev 按卡内定义的注入格式运行时填充。

## 组装序(每张图独立 compose)
```
[产品保真块(品类卡)] → [图型卡块(本张图型)] → [用户卖点&要求] → [platform/region/language 片段]
```
仅 plan(套图)路径带图型卡块;现行 n 单图路径不带、维持现状(A 案并存,#467/#471)。

## 每张卡必含字段
图型(枚举 key) / 用途 / 定调句 / 构图范式 / 失真命门(按严重度) / 与保真块相容注意 / 物化块。
