# 品类卡:食品 / 花生(带壳 · 七彩)

> 第一张样卡。实测产品:嘴嘴熊「高山七彩花生」(自立袋,65g/69g)。
> Schema 见 [_schema.md](./_schema.md)。配套示例见 [../examples/花生-端到端.md](../examples/花生-端到端.md)。

```yaml
category: FOOD
subtype: 带壳花生 / 七彩花生(紫衣)
适用模板族: 族5氛围沉浸场景(默认) · 族4高端商业摄影(单品精修) · 族3极简电商主图

物性: |
  带壳花生:土黄色硬壳,表面有清晰网状脉络与凹凸,壳形不规则、有壳尖,颜色深浅不均。
  七彩花生米(本产品 USP):去壳后花生衣呈**紫罗兰/紫红色**(非普通土黄/红衣),
  半透哑光、表面有细褶皱,颗粒大小不一、双仁常见。
  包装:奶白+浅驼色自立拉链袋,卡通白熊吉祥物(蓝背带裤),浅色棋盘格底纹,金色椭圆徽章,底部棕色净含量条。

失真命门:   # 按严重度
  - 【最高优先级】紫色花生衣被模型"修正"成普通土黄/红衣 → 直接毁掉"七彩花生"卖点。必须显式锁定紫罗兰本色。
  - 花生壳被画成塑料模型般规整、光滑、反光 → 失去农产品真实感。
  - 颗粒"复制粘贴"般雷同、排列过于整齐 → 一眼 AI。
  - 包装中文小字被重绘成糊字/乱码(品牌字高危,见"文字/品牌注意")。
  - 过曝高调导致壳的脉络与紫衣层次被冲掉(参考图3 的高调逆光即此风险)。

保真清单: |
  保留花生衣的真实紫罗兰本色、花生壳的网状脉络与土黄不均、颗粒大小不一与自然散落;
  EDIT 模式追加:保持参考图产品袋的形态、配色、全部文字与卡通图案完全不变。

真实感线索: |
  自然漫射光为主、带一点点方向性硬阴影(花生与台面有真实接触阴影);
  花生表面微油光但整体哑光、非糖浆假高光;
  浅景深虚化背景但前景花生颗粒锐利可见脉络;
  允许个别花生壳开裂、碎壳、轻微散落的偶然感(不要摆得过于整齐)。

推荐镜头光型: |
  50mm,f/2.8 近景浅景深;平视或 30°微俯;
  侧前方自然光勾出壳的凹凸,柔中带一点硬阴影(非柔光箱均匀平光)。

道具与场景: |
  原木桌 / 麻布桌旗 / 白漆木板;少量绿叶、陶碗盛去壳花生米、暖调茶具;
  生活方式居家感 > 棚拍白底。暖调原木(参考图4)比高调过曝(参考图3)更耐看、更不像 AI。

品类禁词:   # 叠加在宪章全局黑名单之上
  - 塑料感 / 塑料光泽(应正向写"天然哑光质地")
  - 糖浆般高光 / 油亮反光(花生不是糖渍坚果)
  - 过度调色 / 鲜艳饱和(会把紫衣调失真)
  - 完美整齐排列(应"自然随意散落")

文字/品牌注意: |
  关键文字仅锁三处,引号 + verbatim:主标题 "嘴嘴熊"、品名 "高山七彩花生"、净含量 "净含量 65g"。
  徽章小字、左侧工艺 fine print **允许虚化**,不要逐条复述(复述越多整袋越易跑偏)。
  文生图模式几乎必糊这些中文 → **带包装出图强烈建议走 EDIT(喂真实袋照)**。

模式建议: |
  图生图 EDIT(主路径):喂真实产品袋照,只重绘背景/道具/光,产品袋与紫花生靠保真清单锁住。
  文生图:仅适合"无包装、纯散装带壳花生/紫花生米"的氛围素材;一旦要带嘴嘴熊包装,文字保真不可靠,转 EDIT。
```
