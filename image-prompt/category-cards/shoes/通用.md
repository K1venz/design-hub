# 品类卡:鞋类 / 通用产品(草案 · 待 prompt 权威复核)

> SHOES 品类**通用卡 —— 产品中性**（运动鞋/皮鞋/靴子/凉鞋/帆布鞋均适用）。
> 鞋类核心失真命门：AI 极易自作主张修改鞋型廓形（鞋尖/鞋跟高度）——鞋型一变产品即不可识别；
> 成对展示的左右方向对称同样是高频 AI 错误。
> Schema 见 [../_schema.md](../_schema.md)。

```yaml
category: SHOES
subtype: 通用(产品中性，不假设具体类型)
适用模板族: 族4高端商业摄影(单品精修,默认) · 族3极简电商主图 · 族5氛围沉浸场景

物性: |
  **不预设鞋型** —— 款式/材质/配色/LOGO 以上传参考图为唯一事实。
  通用特征：鞋面材质多样（皮革/织物网面/绒面革/帆布），橡胶底鞋纹路明显；
  五金配件（金属扣/铆钉/鞋钩）、品牌 LOGO（刺绣/模压/贴标/内里标）、鞋带（若有）。
  主展示角度：侧 45° 最能体现鞋型廓形；可单只展示或成对。

失真命门:  # 按严重度
  - 【最高优先级】鞋型轮廓被改变（鞋尖变圆/鞋跟升高或降低/鞋帮高低变化）→ 产品识别度全失，须每轮重述廓形保真。
  - 皮革质感被画成塑料光泽 → 材质档次失真，一眼假。
  - 织物网面纹理被过度平滑化 → 工艺感消失。
  - 鞋底橡胶纹路消失或被简化 → 功能型细节严重失真。
  - 品牌 LOGO/刺绣/模压字被替换、变形或消失。
  - 成对展示时两只方向相同（应左右脚对称成对，方向相反）。

保真清单: |
  保留鞋型廓形（鞋尖形状/鞋跟高度/鞋帮轮廓精确）、鞋面材质与颜色、鞋底橡胶纹路、
  品牌 LOGO/刺绣/鞋带/五金配件；成对展示时左右脚对称正确、方向相反。

真实感线索: |
  皮革有自然折纹与受控方向性高光（非镜面/非塑料亮光）；织物网面纹理清晰可见；
  橡胶底接地纹路与微凸结构忠实呈现；鞋面光线定向反射而非均匀散射；
  与展示台面有真实接触阴影；鞋带（若有）有自然张弛感，不过于整齐笔直。

推荐镜头光型: |
  50mm，f/2.8–f/4；侧 45° 机位（最佳廓形展示角度）或正侧面；成对摆放时微俯 30°；
  侧前方自然光，皮革面有定向高光但面积克制，柔中带真实接触阴影。

道具与场景: |
  白底主图：零道具；场景图：木板地面/大理石台面/简洁短绒地毯；
  可添鞋盒/鞋垫/素净麻布垫作衬托，道具克制不超 1–2 件，不堆砌无关物件。

品类禁词:  # 叠加在宪章全局黑名单之上
  - 鞋型廓形失真（鞋尖/鞋跟/鞋帮被 AI 改动）
  - 皮革塑料光泽（应"自然折纹与受控方向性高光"）
  - 左右同向（成对展示时的高频 AI 错误）
  - 鞋底纹路消失/平滑化

文字/品牌注意: |
  EDIT 主路径：LOGO 刺绣/模压字/品牌贴标 100% 原样保留，不重打、不替换。
  不在 prompt 里描述具体 LOGO 图形细节（产品中性，以参考图为准）。

模式建议: |
  图生图 EDIT（主路径）：喂侧 45° 产品照，只重绘背景/台面/光，
  鞋型廓形与材质靠保真清单锁住，不脑补任何 LOGO 或款式细节。
  文生图：仅限无 LOGO 纯材质素材；含品牌 LOGO/刺绣一律转 EDIT。
```
