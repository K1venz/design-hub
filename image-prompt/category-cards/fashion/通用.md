# 品类卡:服装 / 通用产品(草案 · 待 prompt 权威复核)

> FASHION 品类**通用卡 —— 产品中性，不假设具体款式**（连衣裙/T恤/外套/裤装/内衣均适用）。
> 服装保真命门与食品不同：面料色彩漂移、版型廓形被改、AI 自由发挥人体 = 此品类三大高危点，保真块须逐条防守。
> 花生专属卡教训：装束/材质/图案描述一旦写死即锁死单品，本卡严格产品中性，以上传参考图为唯一事实。
> Schema 见 [../_schema.md](../_schema.md)。

```yaml
category: FASHION
subtype: 通用(产品中性，不假设具体款式)
适用模板族: 族5氛围沉浸场景(默认) · 族4高端商业摄影(单品精修) · 族3极简电商主图

物性: |
  **不预设款式** —— 服装的版型/廓形/面料材质/颜色/图案/缝线/五金配件/吊牌文字
  一律以上传参考图为唯一事实，绝不脑补未见细节。
  通用特征：有面料质感（纹路/垂感/褶皱）、缝线可见、可能带五金件（纽扣/拉链/铆钉）、吊牌/洗标。

失真命门:  # 按严重度
  - 【最高优先级】面料色彩被"修正"/提亮/改变饱和度 → 黑色变灰、深蓝变浅蓝，品牌色严重失准。须显式锁定"保持原色、不提亮、不改饱和度"。
  - 图案/印花/绣花位置偏移、比例缩放、局部消失 → 设计细节失真，品牌识别度丧失。
  - 版型廓形被改变（A字裙变直筒、圆领变V领、袖长被截短）→ 产品识别度全失。
  - 面料质感被套用假质感（棉布变丝绸光泽、哑光面料变水光感）→ 材质档次与品类失真。
  - 画面出现人物（人脸/手臂/腿部）→ AI 人体失真高风险，且产品保真退位给人体。
  - 吊牌/领标/洗标文字被模型重写或虚化。

保真清单: |
  保留服装版型廓形、面料真实颜色（不提亮、不改饱和度）、图案印花与绣花（位置/比例/配色精确）、
  缝线与五金细节；EDIT 模式：上传参考图里的服装（包括吊牌/领标/洗标上所有文字）100% 原样保留，
  只重绘背景与衬托光线。

真实感线索: |
  面料按真实材质表现（棉布有自然纹路、丝绸有光泽起伏但不过曝、羊绒有绒毛感）；
  服装自然垂坠，保留合理的褶皱与垂感，不要熨烫绷平的僵硬感；
  面料表面细微不均与真实纹路清晰可见；
  平铺：自然散落褶皱；挂拍：受重力的自然悬垂曲线。

推荐镜头光型: |
  50mm，f/2.8–f/4；平铺俯视 30–45° 或衣架正侧挂拍；
  侧前方自然漫射光，柔中带方向性硬阴影，勾出面料立体感与褶皱层次；不用正顶光（会把面料拍平）。

道具与场景: |
  白底主图：零道具，服装平铺或挂拍居中；
  场景图：与服装使用场景相符（卧室衣帽间/户外/简洁地板），道具克制——木质衣架/折叠台面/单件搭配配饰；
  生活感 > 棚拍感；严禁出现无关杂物。

品类禁词:  # 叠加在宪章全局黑名单之上
  - 模特/人脸/人手/人体局部（MVP 合规禁人物）
  - 面料过度亮光/塑料光泽（应按真实材质正向描述）
  - 完美无褶皱/过度熨烫感（应保留自然垂感）
  - 版型廓形失真/被AI改动

文字/品牌注意: |
  EDIT 主路径：吊牌/领标/洗标/绣花品牌字逐字保留，不重打、不翻译。
  不在 prompt 里硬编码具体 SKU 文字（产品中性），硬写反而诱导模型重渲染或改标。

模式建议: |
  图生图 EDIT（主路径）：喂平铺或挂拍参考图，只重绘背景/道具/光，
  服装版型/面料/图案靠保真清单锁住，不脑补任何款式细节。
  文生图：仅适合纯面料/无品牌字的氛围素材；含品牌绣花/吊牌一律转 EDIT。
```

背景与道具：与服装调性相符的干净简洁背景；道具克制，全部与服装使用场景相关，不堆叠无关物件。
画面禁止：改动面料色彩/版型廓形/图案印花/绣花/吊牌文字、面料异常反光与塑料假光泽、出现任何人物与人体局部（含手与手臂）、水印/多余文字、完美无折叠感的过度熨烫摆放。
