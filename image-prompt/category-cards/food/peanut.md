```yaml

subtype: 带壳花生 / 七彩花生(紫衣)
适用模板族: 族5氛围沉浸场景(默认) · 族4高端商业摄影(单品精修) · 族3极简电商主图

物性: |
  带壳花生:土黄色硬壳,表面有清晰网状脉络与凹凸,壳形不规则、有壳尖,颜色深浅不均。
  七彩花生米(本产品 USP):去壳后花生衣呈**紫罗兰/紫红色**(非普通土黄/红衣),
  半透哑光、表面有细褶皱,颗粒大小不一、双仁常见;
  果仁**粒大饱满、充实鼓胀、有真实体积感与重量感**,像刚剥开的鲜花生那样鼓实有肉(不干瘪瘦小)。
  包装:奶白+浅驼色自立拉链袋,卡通白熊吉祥物(蓝背带裤),浅色棋盘格底纹,金色椭圆徽章,底部棕色净含量条。

失真命门:   # 按严重度
  - 【最高优先级】紫色花生衣被模型"修正"成普通土黄/红衣 → 直接毁掉"七彩花生"卖点。必须显式锁定紫罗兰本色。
  - 花生壳被画成塑料模型般规整、光滑、反光 → 失去农产品真实感。
  - 【用户原始痛点·太圆】果仁被画成**完美对称的光滑圆球** → 假。饱满≠滚圆,必须显式"果形不规则、有壳尖、深浅不均、表面带细褶皱、不要完美圆球"摁住。
  - 【用户原始痛点·干瘪】果仁**干瘪瘦小、没肉感** → 没食欲。必须正向写"粒大饱满、充实鼓胀、鼓实有肉、有体积感与重量感"。
  - 【用户原始痛点·太亮假】表面糖浆高光/油亮反光/塑料光泽 → 像糖渍坚果、塑料。应"整体哑光干爽、仅极轻微自然油润"。
  - 颗粒"复制粘贴"般雷同、排列过于整齐 → 一眼 AI。
  - 包装中文小字被重绘成糊字/乱码(品牌字高危,见"文字/品牌注意")。
  - 过曝高调导致壳的脉络与紫衣层次被冲掉(参考图3 的高调逆光即此风险)。

保真清单: |
  保留花生衣的真实紫罗兰本色、果仁的饱满体积感与重量感、花生壳的网状脉络与土黄不均、颗粒大小不一与自然散落;
  EDIT 模式追加:上传参考图里的产品包装(袋型、配色、白熊图案、袋面所有文字与排版)**100% 原样保留——一个字、一个像素都不改、不重画、不翻译**,只重绘包装周围的背景、道具与光线。

真实感线索: |
  自然漫射光为主、带一点点方向性硬阴影(花生与台面有真实接触阴影),侧前方光勾出果粒饱满体积与凹凸;
  花生表面整体哑光干爽、仅极轻微自然油润,严禁糖浆高光/油亮反光/塑料光泽;
  **饱满≠光滑滚圆**:果形自然不规则、有壳尖、深浅不均、表面带细褶皱,不要完美对称光滑圆球;
  浅景深虚化背景但前景花生颗粒锐利可见脉络;
  允许个别花生壳开裂、碎壳、开口带壳露米/双仁、轻微散落的偶然感(不要摆得过于整齐)。

推荐镜头光型: |
  50mm,f/2.8 近景浅景深;平视或 30°微俯;
  侧前方自然光勾出壳的凹凸,柔中带一点硬阴影(非柔光箱均匀平光)。

道具与场景: |
  原木桌 / 麻布桌旗 / 白漆木板;少量绿叶、陶碗盛去壳花生米、暖调茶具;
  生活方式居家感 > 棚拍白底。暖调原木(参考图4)比高调过曝(参考图3)更耐看、更不像 AI。

品类禁词:   # 叠加在宪章全局黑名单之上
  - 塑料感 / 塑料光泽(应正向写"天然哑光质地")
  - 糖浆般高光 / 油亮反光(花生不是糖渍坚果)
  - 过度调色 / 鲜艳饱和(会把紫衣调失真)
  - 完美整齐排列(应"自然随意散落")

文字/品牌注意: |
  **EDIT 主路径(默认):不重打、不翻译任何字——逐字保留上传参考图袋面所有文字与排版 100% 原样**(主标题/品名/净含量/徽章小字/工艺 fine print 全部不动)。

  文生图模式(仅无包装散装素材):带包装中文几乎必糊 → **带包装出图一律走 EDIT(喂真实袋照)**。

模式建议: |
  图生图 EDIT(主路径):喂真实产品袋照,只重绘背景/道具/光,产品袋与紫花生靠保真清单锁住。
  文生图:仅适合"无包装、纯散装带壳花生/紫花生米"的氛围素材;一旦要带嘴嘴熊包装,文字保真不可靠,转 EDIT。
```
