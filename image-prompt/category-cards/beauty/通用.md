# 品类卡:美妆 / 通用产品(草案 · 待 prompt 权威复核)

> BEAUTY 品类**通用卡 —— 产品中性**（口红/粉底/眼影/精华/香水/防晒均适用）。
> 美妆保真命门与其他品类的最大差异：玻璃/亚克力容器的高光控制 = 保住品牌字的第一手段；
> 色号是最高价值信息，任何 AI 调色都是致命失真。
> Schema 见 [../_schema.md](../_schema.md)。

```yaml
category: BEAUTY
subtype: 通用(产品中性，不假设具体品类—膏体/液体/粉体/香水皆适用)
适用模板族: 族4高端商业摄影(单品精修,默认) · 族5氛围沉浸场景 · 族3极简电商主图

物性: |
  **不预设具体产品** —— 瓶型/材质/色号/内容物以上传参考图为唯一事实。
  通用特征：容器材质多变（玻璃瓶/亚克力管/金属泵头/塑料软管），品牌印刷/烫金/浮雕常见；
  内容物可见性按产品结构：膏体哑面/液体透射/粉体饼面；色号是最高价值信息。

失真命门:  # 按严重度
  - 【最高优先级】玻璃/亚克力瓶身高光过曝 → 大白块淹没品牌文字与瓶身形态，须侧光控制反光面积。
  - 色号/内容物颜色被 AI "修正"：口红改深改浅、眼影色盘色块错位 → 品牌色号严重失准。
  - 金属泵头/盖帽被画成塑料质感 → 产品档次失真。
  - 瓶身棱角/边缘被 AI 磨平磨圆 → 产品轮廓失真。
  - 品牌字/产品名在高光反射区消失或扭曲变形。
  - 透明瓶身内容物颜色被随机改色。

保真清单: |
  保留瓶身外形/材质/透明度、色号与内容物颜色（忠实原色，不提亮不调深调浅）、
  品牌文字与标签图案（含高光区不消失）、金属/玻璃/塑料各部件的材质感。

真实感线索: |
  玻璃折射高光为小亮点或高光线，而非大白块；高光面积控制在瓶身极小范围，品牌文字保持可读；
  金属泵头/盖帽有细腻金属反射感；哑光膏体呈柔和漫散射，无油亮感；
  瓶身有真实接触台面阴影；环境反射小面积可见（柔和窗光映射）。

推荐镜头光型: |
  50mm–85mm，f/2.8–f/4；平视或 30° 微俯；
  侧前方 45° 漫射光，防玻璃正面过曝；高光区面积控制在瓶身 ≤15%。

道具与场景: |
  白色大理石台面/米白棉布/浅调原木板；干燥花/单颗卵石/素净棉质垫布为道具上限；
  轻奢生活感；严禁堆满无关美妆产品，只展示当前上传产品。

品类禁词:  # 叠加在宪章全局黑名单之上
  - 玻璃大白块高光/镜面过曝（应"小亮点/高光线"）
  - 色号失真/提亮/改色（最高价值信息，不可改）
  - 金属泵头塑料感（应"细腻金属反射"）
  - 无关美妆品堆砌

文字/品牌注意: |
  EDIT 主路径：品牌名/产品名/净含量/成分关键字 100% 原样保留，不重打、不翻译。
  玻璃瓶高光区品牌字易消失 → 侧光控制高光面积是保字的第一手段；
  不在 prompt 里硬编码具体 SKU 文字（产品中性）。

模式建议: |
  图生图 EDIT（主路径）：喂产品参考图，侧光重绘背景/道具/光，色号/瓶型靠保真清单锁住。
  文生图：无品牌印刷/纯材质素材可用；含品牌印刷产品一律转 EDIT（文字保真不可靠）。
```
