# 品类卡 Schema(作者指南)

> 品类卡 = 注入给 agent 的「这类产品该怎么拍、最容易在哪翻车」的结构化知识。
> **多品类扩展的唯一动作:照此 schema 写一张新卡。** 宪章、组装逻辑、代码一律不动(OCP)。
> 一张卡对应一个 `domain/enums.py: Category`(或其细分)。当前已建:[food-peanut](./food-peanut.md)。

每张卡必须含以下字段(缺字段 = 卡不合格,agent 会按宪章兜底但质量下降):

```yaml
category: <对应 Category 枚举,如 FOOD>
subtype: <细分,如 "带壳花生 / 七彩花生";可留 "通用">
适用模板族: <族3极简 / 族4高端 / 族5氛围 …,可多选,标默认>

物性: |
  这类产品**客观长什么样**:形态、材质、结构、颜色。
  越具体越好(色卡级),这是 agent 描述产品的事实底座。

失真命门: # 按严重度排序,第一条最致命
  - <这类产品 AI 最容易画错/改坏的点 1>  ← 标"最高优先级"
  - <点 2>
  - <点 3>

保真清单: |
  一句**正向**陈述,列出"必须保留不变"的要素(供宪章 §2.2 每轮重述用)。
  EDIT 模式直接引用。

真实感线索: |
  让这类产品显真实的**光/质地/景深/瑕疵**线索(正向、可执行)。
  对应宪章 §2.4。

推荐镜头光型: |
  焦距/光圈/机位 + 光的方向质地(不含色温,色温归风格卡)。

道具与场景: |
  这类产品**可信的**环境与点缀(生活方式优先于棚拍)。

品类禁词: # 这类产品特有的、会催生假感的词(叠加在宪章全局黑名单之上)
  - <词1>
  - <词2>

文字/品牌注意: |
  这类产品包装/标签的文字特点 + 保真注意(供宪章 §2.1 用)。

模式建议: |
  文生图 vs 图生图 EDIT 在这个品类各适合什么、风险点。
```

## 写卡三原则
1. **写命门,不写百科**:别堆产品知识,只写"AI 在这类产品上最容易犯的错 + 怎么正向防"。
2. **正向、可执行**:每条都要能直接进 prompt,不写"要高级"这种空话。
3. **色卡级具体**:颜色给具名色/HEX,质地给可见特征(脉络/褶皱/油光)。
