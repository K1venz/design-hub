## 二、10 条通用编写法则（跨所有族）

### 法则 1：场景/风格定调必须放第 1 句
模型对前置词的权重最高。所有样本的第一句都是定调：
- "顶级商业摄影：..." / "3D电影感，C4D风格，..." / "极简主义韩系美妆电商海报。..." / "OC 渲染，..."

### 法则 2：用"色卡级"色彩描述，不用泛词
- ❌ "暖色调"
- ✅ "鼠尾草绿、橄榄绿、牛皮纸原木色、奶油白、浅咖色"
- ✅ "天猫品牌红（#E60012）与暖金渐变，辅以深空蓝夜幕"

### 法则 3：产品本体用"材质+结构+细节"三段描述
- "哑光黑钛金属质感" + "球形透明上盖" + "蓝宝石玻璃盖板上极其轻微的指纹油膜感"

### 法则 4：预判歧义，主动约束（命门）
针对模型常犯错误前置防御词：
| 风险 | 防御写法 |
|---|---|
| 产品被遮挡 | "手指不能遮挡产品核心结构" |
| 肖像权 | "原创模特，非明星脸，非真人复刻" |
| 产品变形 | "严格保持产品原有外观、结构、比例不变" |
| 镜面乱反射 | "镜面反射要干净，不要出现杂乱人脸" |
| 过度修饰 | "可以有轻微速度线，但不能变成复杂声波特效" |

### 法则 5：反向约束用中文场景化否定，不用 SD tag
- ❌ `low quality, blurry, distorted, watermark`
- ✅ "不要电商促销感、不要廉价电商风、不要洗衣房场景、不要全身穿搭展示"

### 法则 6：文字/版式信息单独成段，精确到字
含文案的图，文字描述必须独立段落，覆盖：内容 + 位置 + 字号 + 字重 + 字体名 + 颜色。
- "顶部主标题「自然萃取 养生咖啡」，现代中文黑体（思源黑体 Heavy），字重粗、字间距略紧、居中、深灰绿色"

### 法则 7：镜头语言显式化（摄影类）
- "50mm标准镜头，低角度轻微仰视，近景特写，大光圈f/1.8浅景深"
- "等效24mm广角，戏剧性低角度仰拍，第一人称视角"

### 法则 8：光影描述要带方向+性质+效果
- "侧上方柔和暖光，暗调氛围，明暗对比强烈，金属边缘散发柔和金色辉光、轮廓光晕"

### 法则 9：构图明确占比+视角+留白
- "产品居中占据画面 65%-70% 视觉区域，45° 斜角特写 + 轻微低角度仰拍"
- "上下留白充足，重心沉稳，黄金分割点"

### 法则 10：质量词收尾 + 比例参数
- 收尾："8K超高清，商业广告风格，视觉冲击力强，竖版构图"
- 比例：GPT-image 用中文"3:4竖版"，即梦/MJ 用 `--ar 3:4`

## 三、各模板族骨架公式（变量槽用 {} 标记）

### 族 1：大透视广告海报（最高频，9 份）

```
创作一张 {比例} 竖版高时尚大透视{品类}广告海报。
主题产品是{品类}品牌「{虚构品牌名}」的一款{颜色+材质}{品类}。
画面采用高级时尚杂志广告风格，前景是原创时尚模特单手{持握动作}，
产品靠近镜头形成强烈近大远小的大透视冲击。
{产品关键结构清单}必须清晰完整，手指不能遮挡{核心部位}。

后景是一位原创时尚模特，非明星脸，非真人复刻，
穿着{色系}的{风格}造型，姿态{姿态描述}。
背景为{色A}到{色B}的高级渐变影棚，
加入超大低对比英文关键词 "{大写英文词}"，文字半透明、被裁切、融入背景。

海报排版像真实{品类}品牌广告：
品牌名 "{品牌英文}"，主标题 "{英文标语}"，
中文短副标"{中文副标}"，
小字信息 "{规格1} / {规格2} / {规格3}"。
整体要{正向风格词}，不要{负面1}，不要{负面2}，不要{负面3}。
```

**变量槽**：比例、品类、虚构品牌名、颜色材质、持握动作、产品关键结构清单、核心部位、色系、风格、姿态、色A/B、大写英文词、品牌英文、英文标语、中文副标、规格×3、正向风格词、负面×3

## 五、Prompt 生成引擎逻辑（伪代码）

```python
def generate_prompt(brief: Brief, target_model: str) -> tuple[str, str]:
    # 1. 选模板族：物料类型 + 风格 → 族
    family = select_template_family(brief.material_type, brief.style)

    # 2. 视觉理解辅助补全产品描述
    product_desc = vision_assist(brief.reference_images)  # 类型/主色/材质/形状

    # 3. 按族骨架填槽
    skeleton = TEMPLATE_FAMILIES[family]
    slots = {
        "品类": brief.category,
        "虚构品牌名": gen_brand_name(brief.category),       # 词库
        "色卡": COLOR_LIB[brief.style],                     # 词库 A
        "产品描述": product_desc,
        "文字版式": render_typography(brief.copy),          # 法则 6
        ...
    }
    positive = skeleton.fill(slots)

    # 4. 追加防御词（法则 4）+ 负面（法则 5）
    positive += AMBIGUITY_GUARD[brief.category]             # 词库 C
    negative = NEGATIVE_LIB["通用"] + NEGATIVE_LIB[brief.scene]  # 词库 B

    # 5. 质量词 + 比例（法则 10）
    positive += QUALITY_LIB[target_model]                   # 词库 D
    positive += format_ratio(brief.size, target_model)

    # 6. 模型差异化后处理
    positive = MODEL_PROVIDERS[target_model].postprocess(positive)

    return positive, negative
```

## 七、关键结论

1. **电商 Prompt 不存在通用结构**，必须按 9 大模板族分别处理
2. **GPT-image2 的真正优势是文字版式 + 复杂场景**，纯产品图用便宜的国产模型即可
3. **预判歧义 + 中文场景化负面** 是质量命门，必须建词库
4. **色彩用色卡、文字用独立段落、镜头用摄影术语** 是高级感的来源
5. 这套规则**可被程序执行**：模板骨架（填槽）+ 5 个词库 + 模型后处理 = Prompt 编排器的完整实现规格
