## 0. 功能（已定）

用户拿**自己某次成功出图**（单图/套图张/复刻产物皆可，Q-δ）+ 新 prompt + edit_mode → 再过一次 `/images/edits` → 出 **1 张**（Q-ε）新图、独立新 job + parent_job_id、落 generate 桶、复用 provider/cost guard/SSE/history **零新出图链**。可迭代多轮（深度/分叉无硬上限 YAGNI）。
- **端点（Q-α lean，dev 定）**：新瘦路由 `POST /listing/edit`（沿复刻 (b) 先例）。
- **入口可寻址字段（#638/#639 锁）**：走**读模型**（ListingImageOut 加可寻址 handle）、**SSE 契约冻结**（图的身份只一份）；前端 task_completed 后补拉 job 详情取 handle。

## 1. 已定契约（QA 断言依据，#642/#643/#644）

- **edit_mode ∈ {delta, full}**、delta=默认。
  - **delta（微调）**：锁产品本体+品牌文字+**上一版构图基底**、只 apply 增量；**ratio/category 继承父 job**（换比例=重构图≠编辑）；prompt/modifiers 叠新。
  - **full（重做）**：上一版作场景起点 + 全新重绘；**ratio/category 可改**；产品+文字仍锁死。
- **D2 链根锚（硬约束，#635/#637/#642）**：保真锚 = **迭代链根的原始上传产品图**（uploads 桶 role=product，parent 链走到 NULL=根）、**绝不取上一轮产出**（失真不可逆、锚上一轮=漂移逐轮叠加）。**两档都带锚**。喂图 = 源图(被编辑基底)1 + 链根锚 1..3 = **2..4 张**（复用 /clone 双喂机制、喂序即角色、块内角色识别句）。clone 产物的链根锚 = clone 时的产品上传图（通路同构）。
- **Q-γ 编辑不引图型卡、不支持 overlay_texts**（改图上字=对卖点图 full 重做）；源图是套图某图型张时，图型徽标**继承父张 image_type 仅作展示、不进组装**。
- **owner 隔离 P0**：源图 job + 链根 job **双核 user_id**；非本人/不存在/畸形/**失败张作源** → **404 anti-enum**（0032，不区分不存在与存在但失败/非本人；防 0039）。
- **成本**：每次 edit = 1 次真实 edits（n=1）→ 按次单计入 cost_ledger + 预算闸；UI 展示**单次 + 迭代链累计**。
- **回显**：SummaryOut 带 edit_mode（null=原生单 / ✎微调 / 重做 轻徽标）；DetailOut 带 parent_job_id + edit_mode + 源图回显（source_image_key 签 url「改自这张」、只读不可换）。
- **async+SSE 同 0011**、失败 fail-fast；quality MVP 默认档（Q-ζ，不压字=无 high 需求）。
