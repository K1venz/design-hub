## 二、成本红线

- 红线：真实出图全程 ≤ 2 张（每次 n=1）。
- 实际：真实 API 调用 **2 次** = 图生图 edit（超时，回落 mock，未产图）+ 文生图 text2img（**成功，真实出图 1 张**）。
- **真实成功出图 = 1 张**，守住红线。后续选稿/改稿/导出/仪表盘均复用这 1 个真实 job + 1 个 mock job，未再出图。

## 六、通 / 断 总结

- **通**（生产可用）：认证授权全链、角色矩阵门禁、工作台 CRUD、**真实 gpt-image 文生图出图**、
  落库（MySQL 10 表）、异步队列（arq+Redis）、SSE 进度、选稿评分/可用率、改稿单+交付强校验、
  多格式导出+zip+命名归档、成本仪表盘 5 维。
- **断 / 待修**：① 图生图 edit 真实端点超时（P1，**主业务图生图保真链路当前不可用**，仅文生图可用）；
  ② 监控可观测性整包缺失（P2）；③ fallback 成本账不回正（P2）；④ SSE 晚订阅丢事件潜在竞态（P3）。
- 一句话：**骨架全通、真实文生图打穿；图生图 edit 与监控是两个必须补的硬缺口。**
