## 四、执行顺序（env 一通即跑）

1. ops 交付 8444 隧道口 + 库桶就绪 + 只读 mysql 口子。
2. `QA_BASE=http://localhost:8444` **干跑** `listing_acceptance_batch.py`（只 upload）→ 自查 upload url 落 **qa 桶**、DB=design_hub_qa（安全闸）。
3. **零成本批**：`listing_real_boundary.py`（A1/A2/A2+/D2/F3）→ 边界契约回归。
4. **n=1 批**：`listing_history_e2e.py`（A3/B/C1/C3/D1/E）。
5. **批量真实**：`QA_CONFIRM_COSTED=1 listing_acceptance_batch.py`（A4/F1/F2/E 聚合）。
6. **0034**：generation 出 1 张 → `generated_image.url` 裸 key 断言 + TTL=10 真复现。
7. A–E 全绿 + F 采样达标 → 回填 ISSUE-0035、翻牌「已修复」、放行；爆 bug 指 dev（代码）/ PM（口径）。
