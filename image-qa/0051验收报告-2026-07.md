## 三、验收 6 条逐条结果

### 条 1：持久化不丢 — PASS

```bash
# POST /chat/messages（触发澄清轮，零出图成本）
POST /chat/messages {"message":"帮我设计一张产品图"}
→ event: session  {"session_id": "e92bdd7ecdd04170a19cd414988a2cd2"}
→ event: assistant_delta  {"text": "请问"}
→ event: assistant_delta  ...（流式吐字中文澄清问题）
→ event: assistant_end

# GET /chat/sessions 有该会话
GET /chat/sessions
→ [{"id":"e92bdd7ecdd04170a19cd414988a2cd2","title":"帮我设计一张产品图","updated_at":"2026-07-06T08:39:16","message_count":2}]

# GET /chat/sessions/{id} 转录含 user+assistant 消息、seq 有序
GET /chat/sessions/e92bdd7ecdd04170a19cd414988a2cd2
→ messages[0] seq=0 role=user    content="帮我设计一张产品图"
→ messages[1] seq=1 role=assistant content="请问您是否已经上传了产品图？..."
```

### 条 4：owner 404 anti-enum — PASS

```bash
# 用户 B GET 用户 A 的 session → 404（非 403，不泄漏存在性）
GET /chat/sessions/e92bdd7ecdd04170a19cd414988a2cd2  [Token=B]
→ HTTP 404  {"error":"not_found","detail":"会话不存在或无权访问：..."}

# 用户 B DELETE 用户 A 的 session → 404
DELETE /chat/sessions/e92bdd7ecdd04170a19cd414988a2cd2  [Token=B]
→ HTTP 404  {"error":"not_found","detail":"会话不存在或无权访问：..."}

# 用户 B 列表 → 空
GET /chat/sessions  [Token=B]
→ []
```

### 条 5：删除 CASCADE — PASS

```bash
# 用户 A 删自己 session
DELETE /chat/sessions/e92bdd7ecdd04170a19cd414988a2cd2  [Token=A]
→ HTTP 200  {"ok": true}

# 再 GET 该 id → 404
GET /chat/sessions/e92bdd7ecdd04170a19cd414988a2cd2  [Token=A]
→ HTTP 404

# 列表该会话消失
GET /chat/sessions  [Token=A]
→ []

# DB 级验证（CASCADE 删掉 chat_message 行）
SELECT COUNT(*) FROM chat_message WHERE session_id='e92bdd7ecdd04170a19cd414988a2cd2'
→ 0（行被 CASCADE 删除，新 session 的 2 条消息保留）
```
