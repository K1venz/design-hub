## 0. 现行代码基线（QA 读码锚点，断言以此为准）

`listing_service.py` 现行成本/失败先例（`generate()`，listing_service.py:46-90）：
- `estimate = unit_cost × n` → `guard.precheck_and_reserve`（全额预扣）

## 1. 终稿契约（三方对 #485 收敛，QA 断言依据）

- **图型**：MVP = 3 显式图型 **白底/场景/卖点**（中文 key **定稿**，coordinator #486 补裁；卡文件名=枚举 key 零映射）；第 4 型随智能匹配进 backlog。未知图型 → 400。
- **plan**：`POST /listing/generate` 可选 `plan` dict `{"白底":1,"场景":2,"卖点":2}`；总数 3~10、默认 1/2/2=5；未知图型/单型<0/Σ<3 或 >10/全 0 → 400。
- **A 案并存**：plan 与 n 两流并存；**compose 双模式**——plan 路径=保真块×图型卡×用户文本×modifier，n 单图路径=现行三层**无图型卡块**（单图流零破坏）。⚠️ plan 与 n **同传语义**契约须写死（QA 留用例，dev 契约落字）。
- **overlay_texts**（Q3 终版）：top-level 可选 `list[str]`，≤2 条、每条 ≤12 字；仅 plan 含卖点图（≥1）时合法，**带了但无卖点图 → 400**（前端提交剥离、后端 400 兜底）；填 → 卖点图卡内引号 **verbatim** 压图（0038 质控可断言）；**不填 → 卖点图无字**纯细节特写（合格形态）。不落库、零 DB 变更。
- **D2 = SSE 档**：失败张原因仅 SSE 即时可见、历史不留痕（零 error 列）；job 部分完成沿 0030、image_type 标签可推断缺哪型几张。
- **失败张重试 = MVP 不做**（known-limits：可整单重出）；单张重试端点进 backlog。
- **图型标签贯穿**：请求(plan) → SSE `IMAGE_GENERATED` payload 加 `image_type` → 历史落库（D1）→ `ListingImageOut.image_type`。
- **并发**：Semaphore 窗口 W=5 分批；guard 预扣按 Σplan 一次性不随批拆；全套 P95 记录不设硬阈。
- **schema 签字清单**（dev #487 已发、用户亲签后才动；全 additive 可空、零数据迁移）：`listing_image.image_type VARCHAR(16) NULL` + 0040 三列 `listing_job.parent_job_id VARCHAR(32) NULL` / `listing_job.source_image_key VARCHAR(128) NULL`（对象键非签名 url，绕 0034）/ `listing_job.edit_mode VARCHAR(8) NULL`。不落库：overlay_texts、plan、error 列。
- **图型卡**（prompt #489 已交付，commit f003ac2，`image-prompt/image-type-cards/`）：第四类卡、与品类卡正交、**产品中性**（#366）；**QA 逐字核对清单 = 4 个物化块**——白底 ×1（防抠图悬浮：强制接触阴影/投影/方向光）、场景 ×1（无人物含手/手臂、不堆杂物）、卖点 ×2（registry 按「图型+有无 overlay_texts」选块：无字版纯静态逐字核；有字版**模板**——静态部分逐字核、`{overlay_texts}` 槽按卡内格式**全角引号顿号「{c1}」、「{c2}」**注入，引号是 prompt 锁定格式、不要求渲染在图上）。场景图 MVP 无人物（Q1）；白底跳风格卡（Q5 卡内写明）；有字版 quality=high。
- **默认档 = 套图**（裁决二）+ 免费额度 5 张：UI 默认即套图 1/2/2 → **「默认配置真出图」铁律对象变为默认套图 5 张（≈¥2.00/次）**，prod smoke 频次自律（仅部署后一次）。
- ratio 全套统一（请求级 ratio 沿用、每型不异 ratio）；平台/地区/语言收窄全沿用、对全套生效。

## 2. 验收维度（按优先级）

| # | 维度 | 严重度 | 验收点 |
|---|---|---|---|
| T1 | **图型正确性·标签契约** | P0 | 每张产出带 image_type（SSE + job 详情/历史都标）；分布=请求配比（1/2/2 → 标签计数恰 1/2/2）；视觉核每型像该型（白底=纯白底带真实投影非抠图悬浮、场景=环境叙事、卖点=细节特写）。 |
| T2 | **边界 fail-fast** | P0 | Σ<3 / Σ>10 → 400；单型 0 合法；全 0 → 400；负数/非整数 → 400/422；未知图型 → 400；plan 与 n 同传 → 按契约落字断言。 |
| T3 | **部分失败=现行先例** | P0 | 部分失败 → job 部分完成（0030）、成功张带标签、失败原因 SSE 可见（历史不留痕不判 fail）、**只计成功张**；全失败 → rollback 整单退；批间失败语义跨批成立。 |
| T4 | **保真 × 图型矩阵** | P0 | 通用保真块在每个图型生效：多产品（花生+润喉糖）× 3 图型矩阵逐张核「保真+无堆砌+无跨产品泄漏」——防图型卡版「万物皆花生」。卖点/场景发挥不得牺牲保真。 |
| T5 | **overlay_texts 矩阵** | P0 | 见 TT-15~19：400 矩阵 + verbatim 视觉核（填啥图上逐字是啥，0038）+ 不填无字。 |
| T6 | **成本守卫按 Σplan** | P1 | precheck 按 Σplan 预扣；预算不足 → 整单拒；成功张 reconcile 实付。 |
| T7 | **SSE 逐张回显** | P1 | 逐张到达带 image_type（分批节奏下张序可乱**标签不可错**）；`?access_token=` 同 0011；完成后 job 详情与 SSE 累计一致。 |
| T8 | **owner 隔离 + 历史** | P1 | 套图 job 沿用 owner 隔离（404 anti-enum 0032）；历史带 image_type、仅本人可见；D1 迁移生效断言（签字后）。 |
| T9 | **单图流零破坏 + 默认组合** | P1 | A 案回归：现行 n 流全套既有回归继续 PASS、单图 compose **无图型卡块**；不传 plan 走单图、默认套图配比=1/2/2；modifiers 收窄沿用全张生效。 |
